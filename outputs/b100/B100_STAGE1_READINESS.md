### 必须记住的保留意见
- InChIKey 由记录的 SMILES 重算, 必须一致. 但 InChI 归一化可移动氢, 因此该检查抓不到互变异构体替换

## 七、第一阶段发现并修复的缺陷

### 家族规则 SMARTS 被逗号分割破坏
- **影响：** amine 的正则 [NX3;H2,H1,H0;!$(NC=O)] 内含逗号, 被 split(',') 切成三段无效片段, 导致 28 个含胺基分子被误归为醇类, amine 家族计数为 0
- **修复：** 规则表改为 SMARTS 元组, 不再按逗号切分; 并重排优先级
- **验证：** amine 由 0 恢复为 23 个

### 相态审计只覆盖 22 个分子
- **影响：** 306 个『合格』分子中 290 个从未检查相态
- **修复：** 把同一判据扩展到全部候选 (B100-3)
- **验证：** 37 个通过相态验证, 其余标记 UNKNOWN 而非默认液态

### v04 有 135/248 行无法追溯到账本
- **影响：** 这些行的 value 无 measurement 支撑, 不能进入以测量级可追溯为核心价值的数据集
- **修复：** 准入时标记 UNTRACEABLE 并排除出合格集
- **验证：** core traceability = 113 matched / 135 untraceable
