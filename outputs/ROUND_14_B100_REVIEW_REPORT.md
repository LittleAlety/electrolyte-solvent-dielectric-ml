## 一、最严重缺陷：110 个熔点是假的

### 1.1 缺陷

`fetch_pubchem_mp_b100.py` 在没有单位标记时回退到「取任意字符串里第一个
−150..400 之间的数字」。而 PubChem/HSDB 的描述以化合物名开头，于是：

| 假值 | 分子数 | 来源 |
|---|---:|---|
| 1.0 °C | 85 | `"InChI=1S/..."` 里的 **1** |
| 2.0 °C | 18 | 名称里的数字 |
| 3.0 °C | 6 | 同上 |
| −1.0 °C | 1 | 同上 |

这些假值全部通过「mp < T」判据，于是被认证为液态。

### 1.2 后果

**「257 个相态验证分子」这个说法是假的。** 真实可验证的只有 **147** 个。

### 1.3 修复

1. **删除裸数字回退路径**，只接受带 `°C` / `°F` 标记的值
2. **加压力限定词过滤**：`mm Hg` / `kPa` / `@` / `760` / `torr` 等出现时
   该值是**沸点**，不得当熔点

第 2 点还纠正了反向错误：此前把
`1-Iodopentane 157 °C @760 mm Hg`、`diiodomethane 181`、
`isobutyl benzoate 242` 等**沸点当熔点**，**误排了 7 个真实液态分子**。

### 1.4 验证

重抓后缓存中 `ASSUMED` 值**归零**。

## 二、硝基 SMARTS 永不匹配

RDKit 把硝基表示为电荷分离形式 `[N+](=O)[O-]`，
而规则写的是 `[NX3](=O)=O` —— **结构上不可能命中**。

**后果：**
- `nitro` 家族读数 **0**
- 14 个硝基化合物 + 6 个硝酸酯被误归为 `amine`
- 因此「amine 家族优于基线（MAE 9.0 vs 14.8）」实际是硝基化合物的结果

**修复后：** nitro **0 → 16**，amine **21 → 7**（真实的胺与苯胺）。

## 三、极化率列导致高介电尾部被静默截断

### 3.1 发现

`polarizability_au` 对 **36/257** 个分子缺失。逐一验证 `--pop` / `--alpha` /
`--esp` 后确认：**xTB 6.7.1 根本不输出极化率**。

### 3.2 为什么这是系统性问题

缺失**不是随机的**。36 个里有 **25 个 ε≥20 分子中的 10 个**：

| 分子 | ε |
|---|---:|
| N-甲基乙酰胺 | **178.47** |
| 1-甲基咪唑 | 39.78 |
| 己二腈 | 32.12 |
| 氨基乙醇 | 31.46 |
| 二乙二醇 | 30.95 |
| 2-乙酰噻吩 | 29.19 |
| 三乙醇胺 | 28.11 |
| 二乙醇胺 | 24.69 |
| 三乙二醇 | 23.07 |
| 1,2-丁二醇 | 22.14 |

被丢弃的 36 个平均 ε = **16.68**，保留的 221 个平均 **8.00**。

**因此所有模型都在一个更容易的、目标被截断的子集上拟合。**

这也**解释了 H4 为何功效不足**——强缔合组只剩 15 个，而不是 25 个。
**这是流程 bug，不是数据不足。**

### 3.3 修复

移除 `polarizability_au` 与 `alpha_over_Vm`。理由有两条，都可测量：
1. xTB 不输出，导致非随机缺失
2. 该列本身几乎无信息（单独 R² = **0.036**）

**修复后：共同评估集 221 → 257，H4 强组 15 → 25（达标）。**

## 四、p = 0.0 在算术上不可能

200 次置换的最小可能 p 是 1/201 = 0.005。
原代码报 `p = 0.0` 六次，**高估了证据强度**。

**修复：** 加 +1 校正。

| 项 | 修复前 | 修复后 |
|---|---:|---:|
| E1 置换 p | 0.000 | **0.005** |
| E6 蒙特卡洛 p | 0.0036 | **0.0366** |

**E6 仍显著（p < 0.05），但强度大幅下降。**

---

## 五、「18 个印证」只检查了存在性

原代码的 `in_both` 只判断「分子同时出现在两层」，
而 manifest 描述为「**且两者一致**」—— **这个一致性从未被计算**。

R2 逐一比对后发现 6 个（1-氯丁烷、2,2,4-三甲基戊烷、苯乙酮、CCl₄、
硝基苯、十二烷）在其他文件里根本没有比较行。

**修复：** 必须 ε 相对差 ≤ 5% **且** 温度差 ≤ 5 K 才算印证。

## 六、重复物质未被任何审计发现

全 InChIKey 去重看不到立体异构别名。用去立体化学的构成式分组后发现：

| 组 | 类型 |
|---|---|
| cis-3-辛烯 / trans-3-辛烯 | **cis/trans，是不同物质** |
| cis-4-辛烯 / trans-4-辛烯 | 同上 |
| cis-5-癸烯 / trans-5-癸烯 | 同上 |
| d-柠檬烯 / dl-柠檬烯 | 对映体别名，需处理 |
| dl-2,3-二溴丁烷 / meso- | 需处理 |
| dl-3,4-二溴己烷 / meso- | 需处理 |
| 1-苯基-1-丙烯 / 3-苯基-1-丙烯 | **错标**（后者实为丙烯基苯）|

**7 组同构成，其中 3 组 cis/trans 是真正的不同物质（偶极不同），不合并。**
需处理的只有 **4 个**，去重后约 **253 个不同物质**。

## 七、结果变化（更诚实）

| 指标 | 修复前 | 修复后 |
|---|---:|---:|
| 共同评估集 | 221 | **257** |
| E1 最佳块 R² | 0.477 | **0.290** |
| E4 优于基线家族 | 6/8 | **7/10** |

| **H4 判定** | INSUFFICIENT_POWER | **EXPLORATORY，方向反转** |

### 7.1 H4 方向反转（本轮最重要的科学变化）

功效达标后，方向与假设**相反**：

| 组 | n | 相对 MAE |
|---|---:|---:|
| 弱缔合低介电 | 176 | **0.779** |
| 强缔合高介电 | 25 | **0.670** |

**高介电强缔合分子的预测反而更好（相对误差更小）。**

`supports_h4 = false`。原假设「单分子电子描述符对低介电弱缔合液体预测更好」
**不被支持**。

### 7.2 E1 的新格局

共同集 257、基线 6.908：

| 特征块 | 维数 | MAE | R² |
|---|---:|---:|---:|
| X0 结构 | 15 | 5.650 | 0.131 |
| X1 电子 | 2 | 5.971 | 0.082 |
| 偶极矩单独 | 1 | 5.900 | 0.081 |
| **Xn μ²/Vm** | **1** | **5.227** | **0.175** |
| X0+X1 | 17 | 4.820 | 0.225 |
| **X0+X1+Xn** | **18** | **4.498** | **0.290** |

**注意：X0 现在优于 X1**（0.131 vs 0.082），与 221 分子时的结论相反。
但 **Xn 单列仍然强于这两个块**（1 维 R² 0.175），
「体积归一化项效率最高」这一发现**稳健**。

## 九、测试

新增 `test_b100_review_fixes.py` **11 项**，逐条锁定本轮修复：

- 熔点不得有 ASSUMED 标记
- 裸圆整熔点（无来源标注的 1.0/2.0/3.0）必须为零
- 沸点不得当熔点（压力限定词检查）
- 熔点物理合理（−150..400 °C）
- nitro 家族非空；硝基化合物不得标为 amine
- p 值不得为 0；必须 respect +1 下限
- 重复物质必须被记录，且 cis/trans 不得计为重复
- `phase_verified` 不得硬编码
- 硬门槛对勾不得硬编码
