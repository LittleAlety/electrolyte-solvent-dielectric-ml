## 0. 一句话结论

Ether 的**水平差异是真实的**（中位 ε 跨度 18.26），**结构异质性也是真实的**（5 个可复现类别），但**没有证据表明子族内部存在可靠排序能力**，且**外部数据无法补足氯代醚样本量**（仍为 n=2）。

v7.1 的「池化 ρ=−0.135」解释保持 `EXPLORATORY`，不升级。

---

## 1. v1 → v2 的改进

v7.1 的三类方案把环醚强行塞进 `aliphatic_ether` 或 `other`，导致 THF（若是醚）与 1,4-二氧六环和开链二烷基醚混在一起——但环张力同时改变静态介电常数和描述符对 C–O–C 几何的感知。

v7.2 增加 `cyclic_ether` 类，并置于 `aliphatic_ether` **之前**判定。

### 1.1 规则（互斥、可复现、不使用名称）

| 优先级 | 类别 | 结构判据 |
|---|---|---|
| 1 | `chlorinated_ether` | 有 C–O–C 且 ≥1 个共价 C–Cl |
| 2 | `aromatic_ether` | 存在芳基–O 键 |
| 3 | `cyclic_ether` | C–O–C 中至少一个碳是环原子 |
| 4 | `aliphatic_ether` | 非环 CX4–O–CX4 |
| 5 | `other_or_ambiguous` | 其余 |

`name_matching_used: false`。契约测试 `test_ether_subtypes_reproducible_from_smiles` 独立重跑规则并要求标签完全一致。

### 1.2 分类结果（16 个冻结 ether 分子）

| 子族 | n | 分子 |
|---|---|---|
| `chlorinated_ether` | **2** | 3-氯-1,2-环氧丙烷、β,β'-二氯二乙醚 |
| `aromatic_ether` | 5 | 苯甲醚、乙氧基苯、对甲氧基甲苯、邻甲氧基甲苯、二苯醚 |
| `aliphatic_ether` | 6 | 二丁醚、丙醚、1,1-二甲氧基乙烷、1,1-二乙氧基乙烷、异丙醚、乙醚 |
| `cyclic_ether` | **2** | 1,4-二氧六环、三聚乙醛 |
| `other_or_ambiguous` | 1 | 乙烯基醚 |

**官方 `family` 列未修改**，所有 16 个分子的 `family` 仍是 `ether`（契约测试强制）。

## 3. 三个假设的检验

### H1：子族之间存在水平差异 → **`SUPPORTED`**

中位 ε 跨度 18.26，氯代醚（21–22.6）远高于脂肪醚（3.1–4.3）。

**机制**：氯代醚的 C–Cl 键引入强偶极，模型用一套「醚」特征无法同时拟合两个水平，预测值全部落在 ~3.7–3.9 附近，对氯代醚造成 −18 ε 的低估。

### H2：子族内部存在排序能力 → **`EXPLORATORY`**

- 5 个可算 ρ 的子族中，2 个（aliphatic 0.486、aromatic 0.900）为正
- **但 0 个达到 p<0.05**
- aromatic_ether 的 ρ=0.900 看起来很好，**p=0.087，n=5** —— 这是「n 太小导致的偶然高相关」的典型例子

**不能因为 ρ=0.9 就说「芳香醚子族排序良好」。**

### H3：池化掩盖了子族内真实信号 → **`CONSISTENT_BUT_NOT_SIGNIFICANT`**

- 池化 ρ = −0.135，**p = 0.618**
- 池化 ρ 与 0 无显著差异，因此**不能**用它来证明「池化破坏了真实信号」
- 机制上说得通（两个方向相反的偏差互相抵消），但**统计上没有证明**

## 5. 对计划问题的直接回答

> **ether 的池化失败究竟是结构异质性、子族水平差异，还是单分子描述符本身缺乏排序信息？**

**回答（`EXPLORATORY`）**：

1. **水平差异是真实的、可量化的**（跨 18.26 个 ε 单位），且模型确实无法同时拟合两个水平。
2. **结构异质性也是真实的**（5 个可复现类别，规则无歧义）。
3. **但数据无法区分「池化掩盖了真实排序信号」与「本来就没有排序信号」**：
   - 池化 ρ 不显著（p=0.618）
   - 无任何子族达到显著排序（最佳 p=0.087）
   - 氯代醚 n=2，根本无法计算

**这三个原因不能归为单一答案。** 论文必须如实写成「水平差异已证实、排序机制未解决」。
