## 一、NBS Circular 514 频率审计（本轮核心判决）

### 1.1 问题

扩展表 392 行的 `frequency_mhz` **全部为空**。这是「频率未知」（Q3 缺陷），
还是「来源把该量定义为低频极限」（合法）？

### 1.2 审计方法与结果

| 项 | 数量 |
|---|---:|
| 扩展表行数 | 392 |
| NBS 转录总行数 | 636 |
| **转录中带频率脚注的行** | **127** |
| 扩展表选中行**带**频率脚注 | **0** |
| 扩展表选中行按来源定义视为静态 | **392** |
| 未选中的转录行 | 244 |
| 未选中行中带频率脚注 | **127** |

频率脚注取值：`f=5x10^8 cycles/sec`（57）、`f=4x10^8`（35）、`f=3.6x10^8`（27）等
—— 即 **360–500 MHz 的高频测量**。

### 1.3 判决

> **扩展层 392 行全部来自不带频率脚注的转录行。**
> 因此空白 `frequency_mhz` 应解释为**来源级静态定义**，而非「频率未知」。
> 另有 244 条转录行未被选入，其中 **127 条带非静态频率脚注，已被正确排除**。

**按 Q2 处理是成立的。**

### 1.4 残余风险（必须保留）

来源级定义仍是**集体判断**：若某条测量实际在 400 MHz 下进行而来源未加脚注，
本审计无法发现。因此 Q2 证据必须保留这一保留意见。

## 三、四类完整性缺陷（本轮最有价值的发现）

### 缺陷 1：家族规则 SMARTS 被逗号分割破坏

**现象：** `amine` 家族计数为 **0**，但结构检索显示 **28 个分子含胺基**。

**根因：** `classify()` 用 `smarts.split(",")` 支持多模式，而胺的正则
`[NX3;H2,H1,H0;!$(NC=O)]` **内部就含逗号**，被切成三段无效片段。

**影响：** 若未发现，所有氨基醇（2-氨基乙醇、二乙醇胺、三乙醇胺…）
会被误归为醇类，**分层抽样设计直接失效**。

**修复：** 规则表改为 SMARTS **元组**，不再按逗号切分；并重排优先级
（杂原子身份先于碳骨架）。

**验证：** `amine` 由 **0 → 23**。

### 缺陷 2：离子液体混入中性单分子数据集

**现象：** `sulfone_sulfoxide` 家族 10 个成员**全部是离子液体**
—— 咪唑盐、吡咯烷盐、铵盐 + TFSI 阴离子。

**根因：** TFSI 阴离子的磺酰基匹配了砜的 SMARTS，而扩展表把这些盐记为
`component_count = 1`。

**为何严重：** PLAN B v6.0 明确禁止「离子液体、混合物、金属配合物」进入中性单分子
核心数据集。离子液体的静态介电常数由**离子屏蔽**主导，不由描述符刻画的分子偶极决定。

**修复：** 新增 `audit_b100_neutral_filter.py`，按结构判据排除：
- 单分子净电荷非零 → 离子
- 多不连通片段且至少一个带电 → 盐
- 含金属原子 → 配合物

**验证：** 排除 **27** 个（21 个盐对 + 6 个多组分混合物）。

**重要教训：** 初版中性过滤只作用于 257 个已过相态的分子，因此**看不到**
那 10 个离子液体——它们因缺熔点被相态门槛以**错误理由**移除。过滤器必须作用于
全部 306 个候选。

### 缺陷 3：互变异构体替换（InChIKey 原理上抓不到）

**现象：** 名为 `N-methylacetamide` 的行携带 SMILES `CN=C(C)O`
—— 那是**亚胺酸互变异构体**（methyl acetimidate），不是酰胺 `CC(=O)NC`。

**为何 InChIKey 校验漏掉：** 标准 InChI **归一化可移动氢**，因此
`CN=C(C)O` 与 `CC(=O)NC` 产生**同一个 InChIKey**。身份校验返回 0 个不匹配，
但 xTB 算的正是该 SMILES 对应的三维结构。

**后果：** 亚胺酸给出偶极 **1.07 D**，酰胺真值约 **4.3 D** —— 相差 4 倍。

**修复：** 新增 `verify_b100_smiles.py`，向 PubChem 按 InChIKey 查权威 SMILES
并比较连通性。

**验证：** 240 个 SAME、17 个仅立体差异、**1 个互变异构体缺陷**。
该分子用正确酰胺 SMILES 重算后：偶极 **1.07 → 4.336 D**，重跑校验
**TAUTOMER_OR_FORM 归零**。

**附带修复的第二个 bug：** PUG-REST 的响应键是 `SMILES` / `ConnectivitySMILES`，
不是请求名 `CanonicalSMILES`。初版读错键名导致 257 个全部误报
`PUBCHEM_UNAVAILABLE`。

### 缺陷 4：HOMO-LUMO gap 用错能量列

**现象：** gap 算出 **121 eV**（任何闭壳层有机分子都不可能）。

**根因：** xTB 轨道表有**两列能量** `Energy/Eh` 与 `Energy/eV`。
我抓到的是 **eV 列**，却又乘了 27.211 的 a.u.→eV 转换因子。

**修复：** 直接相减（值已是 eV），并加物理护栏 `0 < gap < 30`。

**验证：** N-甲基乙酰胺 4.45 eV、二甲基碳酸酯 5.90 eV、三乙二醇 10.27 eV
—— 全部合理。

### 关键保留意见

> **226/257 来自 NBS Circular 514 这一份编校来源。**
> 四个 part 文件是同一汇编的分页，**不是四个独立来源**。
> 因此这批分子之间的一致性**不构成独立复现**。

**这支持什么：**
- 大样本单分子描述符建模（257 个分子）
- 化学空间内插值能力评估
- 分层家族留出验证（LOFO）
- 与核心层 31 个 Q1 分子对照

**这不支持：**
- 「结果可跨独立测量方案复现」（88% 同源一份汇编）
- 把 NBS 内部一致性当作外部验证
