# 单分子描述符的有效性边界 —— B 仓最终报告
> 生成器 `build_final_package/1.0.0` · 2026-11-23T10:22:02Z

## 摘要
本报告是 PLAN B 第二仓库的最终交付。研究问题严格限定为**纯液体静态相对介电常数 εr**。

**核心结论：单分子描述符能显著优于平凡基线，但不能提供可检测的筛选价值。**

描述符的有效性边界比预期**窄**：它们抓住了 μ²/V 这一单分子主导项，但没有抓住 Kirkwood g（偶极关联），而后者才是液体 ε 的集体部分。

> **本项目发生过一次结论反转，必须记录在案。**
> B05-E1 的初版因 ridge 回归**缺少截距项**（在标准化空间中强制过原点）而得出「两个模型都劣于常数基线、描述符没有信号」的结论。四位 Reviewer 中的 R1 与 R3 **独立**发现了这个错误。修复后 X0+X1 的 MAE 从 17.29 降至 **6.50**，R² 从 −1.29 升至 **+0.54**。
> 这不是修饰，而是结论方向的改变，且已同步修正 E4/E6/B07 中同一缺陷。

## 三、四智能体审核的实际作用
本项目共进行 4 轮四智能体审核（B02 准入、GVL 冲突、B03 回填、B04 冲突裁决）。**审核的核心价值不是给出 PASS，而是发现主智能体自己的缺陷。**

四审共发现并促成修复 **11 处**缺陷，全部为自身代码/流程问题，其中三处是「判据永不失败」类缺陷：

- B02 队列的 j04 连接失败：`v04row-NNN` 建键却用 `EPSV04-RNNN` 查询，70/70 行全空
- B03 校验器从未打开 `dielectric_v04.csv`：声称与冻结值比对，实际读的是镜像
- B03 账目门是代数恒等式：`len(gap−unres) + len(unres) == len(gap)` 恒成立

每一处都做了**负向对照**（注入缺陷后确认校验器报警），而不是只修不验。

## 四、描述符有效性边界
### E1：结构 vs 结构+电子

| 模型 | MAE | R² | 优于常数基线 |
|---|---:|---:|---|
| X0_structure_only | 10.243548 | -0.110961 | true |
| X0_plus_X1_electronic | 6.788274 | 0.49192 | true |
| **常数基线** | **10.806223** | — | — |

加入 xTB 电子描述符后 ΔMAE = -3.4553，但零分布内部尺度是 0.88 —— **增量价值完全在噪声内**。

### E4：跨域泛化的决定性证据

有 **4** 个分子的最近邻指纹 Tanimoto = 1.000（描述符无法区分二者），但平均绝对误差仍达 **2.7917**。

**这区分了两种失败：**

- 「域外外推失败」→ 可以靠增加数据解决
- 「描述符无法分辨化学上不同的液体」→ **不能靠增加同类数据解决**

此外，适用域判据失效：域内 MAE 5.3405 vs 域外 7.4639，比值 1.398（`NO_USEFUL_SEPARATION`）。

### E6：筛选决策

| 项 | 值 |
|---|---:|
| k（冻结规则） | 3 |
| Oracle Top-k 均值 ε | 37.83 |
| 模型 Top-k 均值 ε | 24.45 |
| Regret | 13.38 |
| P(随机 ≥ 模型) | **0.16** |

**噪声阶梯的反直觉结果：** 加入噪声后 MAE 恶化但 regret **下降**（13.38 → 17.57）。

这不是「脱钩」，而是更强的结论：**模型的点预测对筛选目标有害**，噪声只是在抵消它的偏差。H3 因此得到支持，且方向比预期更严重。

## 五、三个假设的回映
| 假设 | 证据 | 判定 |
|---|---|---|
| **H1** 误差与可靠性有化学空间依赖性 | 家族间 MAE 差异 12.8–21.3，但域内外无系统差异 | 部分支持 |
| **H2** 更精确的电子计算不必然带来更好预测 | ΔMAE 落在零分布内 | 支持 |
| **H3** 回归误差改善与筛选收益脱钩 | 噪声使 MAE 恶化但 regret 下降 | 支持且更严重 |
