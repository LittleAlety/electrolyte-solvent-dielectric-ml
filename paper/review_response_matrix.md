## 1. 本仓可执行的口径结论（正式表述，可直接粘进正文）

### 1.1 A3 —— 漏解「安全定理」的因子 2（交由 W22-1 执行并出读数）

- **形式化**：设第 `k` 格的效应量为 `e_k`，单格最大效应量 `A_axis = max_k |e_k|`。
  一对分子 `(i, j)` 的间距变化满足三角不等式
  `|Δ(d_i − d_j)| ≤ |Δd_i| + |Δd_j| ≤ 2 · A_axis`。
  故**严格**的安全判据是 `|d0| ≥ 2 · A_axis`；现判据 `|d0| ≥ A_axis` 只在两臂效应同向时成立。
- **正式表述（正文口径）**：定理的**严格界**记为 `2 · A_axis`（或按 pair 级重定义
  `A_pair = max_pair |Δ(e_i − e_j)|` 后形式不变）；**实测的「靶向漏 0 次翻转、τb = 1.0000」
  是经验结果，不能反过来证明定理**。正文必须把「定理（严格界）」与「实测（经验零漏）」
  **分成两句话**写。
- **归宿**：`probes/w22_safety_theorem.py` + `reports/w22_safety_theorem.md`（W22-1）。
  阈值改 `2A_axis` 后须**重报**保护格计数与节省率（28.3% / 3.3% 是旧口径，不得沿用）。

### 1.2 A5 —— 还原轴的物理载体（正式表述）

### 1.3 A6 —— 「介电层可以不算」的口径收紧（正式表述）

> **单一连续介质（single continuum）计算不可省**；可以省的是 `ε ≥ 200` 的**高介电细化**
> 与 **ε 扫描**两件事。

- **理由**：既然气相阴离子全部不束缚（A5），还原轴**必须**有连续介质才算物理量；
  因此把「介电层」整体说成「免费」与 A5 自相矛盾。
- **落地位置**：摘要、§3.7、§3.10 三处统一为此口径（原文三处登记待办；本仓 v2 框架文档
  `docs/framework/ranking-electrolyte-materials-v2.md` 的对应段落须同步）。

### 1.4 A2 —— 摘要数字方向自检规则（正式表述）

**规则 R-A2（跑稿前/改稿后各过一遍）**

1. **单调性自检**：任何「降为 / 反而 / 退步 / 反而更差」出现时，先核对两数的数值大小。
   若新数 **>** 旧数（例如 `0.73 > 0.61`），则该方向词在数值上就是错的，必须改写。
2. **解耦论据自检**：解耦（误差降而排序不升 / 误差升而排序更好）的论据**必须引用误差与排序
   方向相反的那一对**，且同一对不得既被用来证明「解耦」又被用来证明「改进」。
   正例：`P1（误差 0.25 eV，τb 0.73）` 对 `GFN2-xTB ΔSCF（误差 4.48 eV，τb 0.91）`
   ——「误差差 18 倍、排序反而更好」。反例（**不可**用作解耦论据）：
   `P0（1.38 eV，0.61）→ P1（0.25 eV，0.73）`，这是误差降、排序升的**正常**方向。
3. **同口径自检**：被比较的两数必须取自同一口径（同池、同 N、同判据），口径不同则先声明。

- **归宿**：原文摘要与 §4 结语的具体改写为 `pending_needs_original`（数字对须以原文为准）；
  规则本身 `executed_in_repo`（本节 + §2 A2 行）。
