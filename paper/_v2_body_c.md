### 3.22 门禁的工程化收口：注册表、引用登记、端点容差与噪声地板（W34–W37）

W33-A 把「态合法性」从诊断提为门禁时，它还是报告里的一张表。W34–W37 做的是同一件事的四次收口：**把纪律变成跑不过就报错的工件**。这一段全部是后验与治理件，0 shot，累计仍 19。

**（1）注册表与守卫同体。** `data/processed/redox_state_legality_registry.csv` 共 **1028** 行（GFN2 4×246 加 ORCA 配对 2×22）；不变量写成一行断言 `legal == geom_ok AND homo_bound AND ea_positive`，失败原因按 `geom > homo > ea` 取首个条款。读数函数 `redox_reading()` 与门禁在**同一次调用**内：合法子集 < 5 直接抛 `RedoxGateRefusal`，**不返回 None**。下游因此既绕不过门禁，也无法把「拒答」当缺失值插补或赋伪值。

**（2）同一（层级，介质）在两个总体上的可宣读性可以相反。** GFN2 气相在 246 普查上合法 52 行（可宣读），但在 R6 的 22 个配对化合物上只有 **1/22**（判不可判定）。因此引用登记表 `probes/artifacts/w35_gated_reference_register.csv` 的 10 行**全部带总体说明**，标记由守卫给出而非手写：`r6_red_gfn2` 与 `r6_red_orca` 标记「不可判定」，四条 `w33a_gfn2_*` 标记「可宣读」，两条 ORCA 读数因合法子集（0、2）均 < 5 而**不给数值**。

**（3）端点判等必须带容差。** W36-A 复算六张逐重复表、全部已发布端点，发现发布值与 `statistics.fmean` 现场复算值**最多差 2 ulp**（1.1e-16 至 2.2e-16）：端点定义为「先对每种子 10 折取均值、再对 5 个锁定种子取均值」，浮点求和顺序一变就落到相邻浮点。因此规则 R5 把判等容差冻结为 **1e-12**，W37-A 再用 AST 扫描把「逐位字符串相等」的端点比较列为禁止写法；`endpoint_of()` 在种子集或折数不一致时抛 `SeedSetDriftError`——端点不允许在漂移的网格上宣读。

**（4）通道噪声地板接进显示层。** 四通道的 s0 与最小信息预算并成一张入口表：介电 **0.4737**、黏度 **0.4903**、轨道 **0.5828**、氧化还原 **0.3695**。缺口到 s0 再到所需 N 的外推链在介电通道上做过一次校验：s0 实测 0.4737 对预测 0.4214、N 实测 129.5 对预测 118.1，相对误差 **8.8%**。

一句话：**门禁、容差与噪声地板在 W34–W37 从「写在报告里的纪律」变成「跑不过就报错的工件」**；它们不产生新的科学读数，但决定了哪些旧读数可以被宣读。

### 3.23 结构不等于功能与取向相关 g：两条被置换零分布检验过的机制读数（W38-B / W38-C）

**（1）结构解释力的上界。** 用 241 个化合物的 Morgan(r=2, 2048 位) Tanimoto 做 1-近邻预测，R² 只有 **0.2503**、Spearman **0.6825**、MAE **7.9869**——这是「只用结构、不用任何物理描述符」能拿到的最宽松上界。把「相似度能不能预测标签差」放到 999 次标签重排的零分布上：Spearman(Tanimoto, |Δε|) = **−0.0607**，z = **−2.1630**、双侧 p = **0.0260**。符号是对的（越像差越小），但幅度极小；而 **Tanimoto ≥ 0.80 且 |Δε| ≥ 30 的对数是 0**，原判据因此在 241 个化合物上无可命中。

**（2）Kirkwood-Onsager 残差。** 取 L(ε) = (ε−1)(2ε+1)/(9ε)、x = μ²/V_m，在 `hbd == 0`（理应 g 约等于 1）域上过原点拟合得斜率 s，定义无量纲相对取向相关因子 `g_rel = (L/x) / median_{hbd==0}(L/x)`。非给体域（n = 159）的 `g_rel` 中位数恰为 1（定义使然），给体域（n = 68）为 **2.5016**；置换零分布均值 1.2670、sd 0.3029，z = **4.076**、p = **0.0060**；leave-top-k-out（k = 1 至 10）只把比值从 2.5163 抬到 2.5602，**结论不依赖极值**。高介电族（ε ≥ 60，机械阈值）里给体 4 个的中位 `g_rel` = **28.07**，对非给体 4 个的 **1.79**，子群比 **15.65**。

这两条合起来给主记分牌一个机制解释：**单分子描述符传不了分子间关联**；缺的那一维是取向相关 g，而它集中体现在自缔合质子性液体上——正好是全域 R² 最拉不动的那一类。

### 3.24 三条判据改法：反解预算、相对判据与比值判据（W38-A / W40-A）

W37/W38 登记了三条「判据本身有设计缺陷」的项，W40-A 一次性落成可复算判据（只读盘上既有产物，0 shot；14 条判据全部为「成立」或「已登记判否」）。

**（1）反解预算。** 原读法「固定 alpha 判精度」把 tau=30、alpha=0.10 处的精度 0.8125 判否。正确问法是反解：**达到 precision ≥ 0.90 所需的最大预算 `alpha*`**。重读后 tau=30 上 **alpha* = 0.06**，该预算下推荐 **10** 条、合并精度 **0.9000**；注册锚点逐位复现（alpha=0.05 精度 **1.000**、推荐 **6** 条）。边界照实登记：**tau=15 上反解为空**（alpha ≤ 0.30 内无预算能守住 0.90），登记为判否——反解只在 tau=30 成立。

**（2）相对判据加指纹盲区判据。** 取代「Tanimoto ≥ 0.80 且 |Δε| ≥ 30」这条零命中的绝对阈值：最高相似度十分位的 |Δε| 中位数对全域中位数之比 = **0.6518**（置换 p = 0.000）；Tanimoto ≥ 0.99 的**盲区**有 26 对，其中 |Δε| ≥ 5 的 4 对（最大 13.252）。最低十分位（9.19）高于最高十分位（6.44），单调性成立。

**（3）比值判据。** 把 W31 从更宽阶梯抄来的绝对门 `0.08` 换成参数化的 **R² 极差除以 AUC30 极差**，在**五个干净阶梯**上同时检验：W28（只取 `grid_fixed_*` 网格臂）**21.04 倍**、W29 **13.71 倍**、W30 **8.09 倍**、W31 **4.18 倍**、W32 **7.27 倍**，全部 AUC30 极差 < 0.02（上限 0.0189）。首次冻结的门是**稳健门 ≥ 4**（最紧一处 W31 = 4.18）加**非单点门「至少 2 个阶梯 ≥ 10」**（W28、W29）。上锚与 W30-A 已发表读数（13.7 / 21.0）逐位一致。

**一条必须写明的口径修正。** W28 那张表原先把 `lever4_morgan_*` 与安慰剂 `lever4_physical_retuned_shuffled_target` 混进同一「阶梯」，会把 AUC30 极差从 0.0056 抬到 **0.5438**（约 98 倍），从而把比值压到 1.29 并让判据假判否。这不是数据问题，是**阶梯定义**问题：比值判据要求阶梯是同一配置网格上的档位，安慰剂臂与换表示臂必须剔除。

### 3.25 第三个轨道与偶极外部层：QM9 的层级对齐与偶极质量审计（W39）

QM9（133,885 分子，B3LYP/6-31G(2df,p) 气相，CC BY 4.0）是本项目覆盖最宽的轨道能外部层：名册 **103 / 241** 命中，比 Batt-P30K 的 73 更宽。它只作**对照与审计层**，数值不进任何标签池或特征列。

| 量 | 值 |
| --- | --- |
| 间隙 Pearson / Spearman | 0.8409 / **0.8856** |
| 中位数比（xTB / B3LYP） | **0.7058** |
| MAE | **2.5329 eV** |
| 线性标定 | xTB = 2.0267 × B3LYP − 8.8729（R² 0.7072，残差 sd 2.0570 eV） |

口径照实写死：**只能谈排序与标定，不得直接互换**——QM9 是气相 B3LYP 轨道能差，我们的是 xTB GFN2 单点。偶极一侧，Pearson 0.7837、Spearman 0.8022、MAE 0.6103 D；把 103 个化合物里「两端基本一致」的 90 个筛出后，签署差中位数是 **−0.3914 D**，即我们的 `dipole_D` 列存在**约 0.39 D 的系统偏置**，其余 13 个 |Δμ| ≥ 1 D 是少数极端样本。

预注册的「构象自由度是主因」被**独立判否**：刚性域 |Δμ| 中位数 **0.4442 D** 反而略高于柔性域 **0.4205 D**（n = 48 / 55）。把 W38-C 的域比换成 QM9 偶极重算，结论不变：**2.9801**（我们的 μ）对 **3.0459**（QM9 的 μ）——机制读数对 μ 的来源稳健。

### 3.26 Onsager 域规则精化与双 μ 读数（W40-C）

W38-C 自己登记过一条自我削弱：域划分继承 RDKit 的 Lipinski donor 定义，**不把水算作给体**——水因此落在「理应 g 约等于 1」的非给体域里，而它的 `g_rel` 实测约 2.2。W40-C 把域规则换成**显式的可给体质子**定义（连在 N/O 上、杂原子不带正电荷、酰胺 N-H 不算），只读既有特征表，0 shot。

**改判的只有 3 条**：water、1-butanethiol、1-pentanethiol。水在旧口径下 `NumHDonors = 0` 被放进非给体域 A，新规则 `donor_h = 2` 把它判入给体域 B。改判之后：

| 量 | 旧口径（W38-C 锚） | 新口径（W40-C） |
| --- | --- | --- |
| 域间 `g_rel` 中位数比 | 2.501616 | **2.581713** |
| 高介电族（ε ≥ 60）子群比 | 15.6504 | **13.4044** |
| 水域归属 | 非给体域 A | 给体域 B |
| 水的 `g_rel` | — | 2.2506（低于给体域中位数） |

三个读数把这条lane的价值钉在「方向不变、幅度变保守」上：旧口径域比被逐位复现（说明改动只来自域定义，不来自实现漂移）；改正水的归属让高介电族域间比**从 15.65 降到 13.40**——旧口径高估了域分离，也就是说这次精化让读数**变保守而不是变好看**。双 μ 一侧，`g_rel` 在两套 μ（我们的与 QM9 的）之间的秩相关是 **0.8007**（n = 76），域间比的相对差只有 **0.0021**：机制读数对 μ 的来源稳健。把 W39 登记的约 0.39 D 系统偏置并入（μ 减 0.3914 D）后，域间比变成 **3.113253**，方向不变但幅度移动 0.2059。

两条照实登记的判否：**（H40c10）** 偏置校正后的幅度移动 0.2059 超过了 0.10 的稳定性门——所以「并入偏置不改变量级」不成立，只能声明方向稳健。**（H40c11）** 水的 `g_rel` = 2.2506 低于给体域中位数 2.5817，因此**改正归属不等于水本身是量级证据**：域纠正解决的是「分错域」，不解决「这一维的单点读数有多可信」。

### 3.27 轨道通道的外部对照层与 PubChemQC 可行性登记（W40-D）

W39 把 QM9 落成第三个轨道/偶极外部层之后，W40-D 做的是**把对照层接进轨道通道**——同样只作对照，不入标签池、不入特征列。

| 量 | 值 |
| --- | --- |
| 对照层覆盖 | **103 / 241** |
| 排序一致性（Spearman / Kendall） | 0.8856 / **0.7114** |
| 未标定绝对差中位数 | **2.577 eV**（102 / 103 条 ≥ 1 eV） |
| 留一线性标定后 MAE | 2.533 eV 降到 **1.602 eV**（下降 36.8%） |

标定把 MAE 降了 36.8%，**不到 50%**，这条读数决定了口径：QM9 层只能作**排序先验**，不能当量级标签；标定式与 W39 冻结值逐位一致，说明两层之间的口径是连续的而不是重新拟合的。

### 3.28 跟踪件的稳定写入：1 / 111 → 「零待迁移」+ 19 行例外登记（W40-B）

W38-E 修好了「重跑脏树」的机制（`write_json_stable`：写入前先与盘上文件比对，除 volatile 键外完全一致则保留原字节），但当时只接线了 1 件，清单里还有 110 件挂着。在迁移完成之前，`worktree_dirty` 与 `artifacts_commit` 这对 AF-12 坐标仍然随时可能被一次无关的重跑破坏。W40-B 把这批写入器逐站点迁移。**第一版执行的教训是：把「全量」当成「全部写入站点」是错的** —— 机械迁移扫出三类**不该动**的站点，全部回退到 W39 字节：

- **(a) 字节被冻结摘要 / 锁前预注册钉死**（16 个 owner）：迁移即让已交付的 summary 与盘上脚本不再一致，例如 erratum 的 `version_1_pins`（锁前冻结）、`walden_dn_channel_summary.json` 与 `eta_epsilon_joint_summary.json` 的 `manifest.builder.sha256`。这类「证据」的意义就是「当时那个字节」，改了等于篡改。
- **(b) 写入站点是追加写**（3 个 owner）：`open(..., "a")` 记一行 JSONL，而稳定写入是**整篇改写**，会把历史行全部抹掉。
- **(c) 原写入器带 `allow_nan=False`**（3 个 owner）：严格 JSON 语义，而稳定写入走 `json.dumps` 默认 `allow_nan=True`，会把 `NaN` 写进交付件。

三类共 **22 个 owner**（其中 1 个同时属 (a) 与 (b)）全部回退，并逐条带**非空理由**登记进 `EXEMPT_WRITERS`；判据 `H40b9` 机械复核「理由非空、且被登记的 owner 确实不含稳定写入」，防止把例外登记当成藏未迁移件的地方。

| 核验 | 读数 |
| --- | --- |
| 复算清单分母 | **121** 件 = 已迁移 **95** + 有理由不迁移 **19**（22 个 owner）+ 待迁移 **0** + 无写入器的历史产物 **7** |
| W38 登记的那 110 件 | **没有一件**仍是「待迁移」（例外登记不计入待迁移） |
| 全仓扫描：有写入调用点名某跟踪件、却未用稳定写入**且未登记例外**的 owner | **0** |
| 抽样连跑（三个已迁移探针各两遍） | 退出码全 0、**零新增脏路径**、产物在重跑后仍为干净 |
| 例外登记自核（H40b9） | 22 个 owner、理由栏全部非空、逐条确认不含 `write_json_stable` |

三条必须写明的口径。**第一，稳定写入的语义是「同一内容不重记时间」，不是「永不写」**：判等只忽略两个标准 volatile 键（`generated_at_utc` / `elapsed_seconds`），任何科学字段变化都会照常落盘。**第二，标准两键之外还有别的易变键**：另有 **33** 件带 `wall_seconds` / `started_at_utc` / `finished_at_utc` 这类字段，已逐件登记在 summary 的 `extra_volatile` 里。**第三，例外登记不是豁免，更不是「已修」**：这 22 个 owner 重跑**仍会弄脏工作树**，这是本件明确保留的已知代价；登记的是「不能迁移的理由」。清单里还有 7 件**没有任何写入器**的历史产物（早轮普查的 evidence JSON）与 1 件**动态路径**写入者（文件名在运行时拼出），两者都按机械规则单独登记，不混入迁移分母。

这条 lane 不产生任何科学读数，但它把「交付字节可标识」从一条承诺变成一条**每次重跑都会被复算的断言**，同时把「哪些字节被冻结点名、因此不能动」这件事第一次写成机械可核的清单。
