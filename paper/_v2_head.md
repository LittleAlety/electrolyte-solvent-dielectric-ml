## 摘要

**背景与动机。** 电解液溶剂的筛选依赖三类可计算物性：静态介电常数 ε（决定锂盐解离与离子对行为）、粘度 η（决定离子电导与低温性能）、以及前线轨道能级 HOMO/LUMO 及其派生的氧化／还原电位窗口（决定正负极界面上的电化学稳定性）。这三类物性在公开文献中以高度异质的形式存在：温度口径不一、来源许可不清、冲突值被静默平均；而轨道与氧化还原通道的数据几乎全部来自量子化学计算，泛函、基组、溶剂化模型与介质常数各异，口径混杂比前两条通道更严重。更要紧的是：**当一条描述符的"排序"本身不稳定时，任何基于它的筛选结论都不成立**——而这一层风险在现有工作中通常既没有被量化，也没有被审计。

**数据。** 我们构建了含 246 种近室温（293.15–303.15 K）纯有机液体、38 个字段的静态介电常数数据集（v0.3.3），按来源分层收录（NIST ThermoML 归档 100 种、NBS Circular 514 210 种、开放获取综述表与一手文献补足至 246 种）。轨道与氧化还原通道另建，取公开可再分发的外部源，包括 Batt-SLM 的 Batt-P30K（MIT 许可，29,519 个分子，ωB97X-V/def2-TZVPPD/SMD(ε=18.5) 级的 HOMO/LUMO/gap/EA/IP/偶极）与同一来源的 Redox-Pot（393 行 IP/EA 与氧化还原电位）；并接入 QM9（CC BY 4.0，133,885 分子，B3LYP/6-31G(2df,p) 气相）作为第三个轨道与偶极外部**对照层**，名册命中 103 / 241。

**框架。** 我们把"描述符决策稳定性"落成一个**单变量台阶框架**：每上一级只改一个因素，于是"位移的符号与量级"和"排序的保真度"可以逐级被归因。轴分两支：`P` 轴是自由分子的电子结构台阶（`P_0` Koopmans 轨道 → `P_1` ΔSCF → `P_2` 隐式溶剂），`C` 轴是条件态台阶（`C_0` 裸分子 → `C_1` `[Li(M)]⁺` → `C_2` `[Li(M)₂]⁺`）。判据在跑之前冻结（预注册），靶值置换必须使读数塌缩（安慰剂），同一化合物不得跨折（组内泄漏审计），失败必须写成交付物的一部分（负结果登记）。

**主结果一：决策稳定性本身可以被量化。** 在 246 化合物普查上，排序统计量 τ_b 的重抽标准差服从**有限总体修正**的闭式 `sd(N) = s0·sqrt(1/N − 1/N_pop)`（6 条实测曲线拟合 rmse ≤ 0.0086）。由此得到母体论文样本量档（N = 12）的**噪声地板 0.122**（六条实测曲线的中位；均值 0.1212，区间 0.0862–0.1519）：任何小于约 0.12 的两档 τ_b 差异，在该样本量下不可读。这把"数据不足"从一句免责声明变成了一条可复算的读数。

**主结果二：还原轴上的跨工作分歧是层级伪影。** 在与母体论文同层可比的六个台阶上，**氧化轴三档的距离全部 ≤ 0.04σ**（0.03σ / 0.03σ / −0.04σ，逐位重合）；**还原轴三档全部 ≥ 2.3σ**（2.32σ / 4.21σ / 6.80σ）且方向一致。进一步把化合物固定、只移动电子结构层级（同一批 22 个化合物：GFN2-xTB ↔ ORCA r2SCAN-3c），**氧化轴 τ_b 只动 −0.043，还原轴 τ_b 由 +0.835 翻到 −0.602**——后者与母体论文的 −0.467 同量级。因此：母体论文还原轴的"失序"不是化合物集合差异、也不是小样本抖动，而是 r2SCAN-3c 层级的真实行为；**本仓 246 化合物普查在还原轴上给出的 +0.826 才是层级伪影**。机制同批可见：还原轴位移极差由 2.55 eV 涨到 11.97 eV（4.7 倍），且气相阴离子不束缚占比由 0.764 升到 1.000。

**主结果三：排序统计量与筛查可用性是两件事。** 在 28 个台阶-轴上，τ_b 与 Top-10 重叠率的秩相关只有 +0.793，而**未解析占比与 Top-10 重叠率的秩相关是 −0.862**；到 Top-30 两者才趋同（+0.953 对 −0.910）。有 4 个台阶-轴满足 `τ_b ≥ 0.50` 却 `Top-10 重叠 < 0.20`，全部落在 `C_0→C_1` 的还原轴上。也就是说：**当未解析占比超过约 0.75 时，τ_b 即便还有 0.57–0.71，头部十名已经不可用**。对筛选叙事，这是一个可直接执行的口径改动，而不是一句解释。

**ε 与 η 通道的位置。** 在更严格的化合物分组口径下（GroupKFold by InChIKey），ε 通道的冻结基线为 0.4091（`0.4091179943351143`）、冻结头条为 0.4766（`0.4766400383507876`）、单表示跨种子端点为 0.5861（`0.5861142332208197`），另有唯一晋升的"有界达标枪" 0.6217（`0.6216672295270079`，五种子下界 0.6000 > 0.55）。η 通道的族级组键 MAE 为 0.1748（`0.17477197208762`）对门限 0.15 只差 0.025，行级 0.1569（`0.15686276760094522`）只差 0.0069——**η 是全漏斗里离过门最近的一处**。

**边界与诚实性。** 我们同时报告负结果与封顶：表示侧的全部增广杠杆（换拟合器、网络叠加、外来化学空间、杂类锚点）已被逐一实测证否；开放许可化合物名册实测上限 161、当前 153（净新增上界仅 +4），因此"靠把化合物数翻倍把 R² 推过 0.60–0.65"这一阶梯前提被证伪并明确封顶；**0.70 在现有许可与物理约束下没有路径**。第 24 周的两条新臂给出了七条判否的负结果（H1 / H2 / H4 / H5 / H9 / O3 及若干档），全部在册；W34–W40 的治理与后验件又新增 6 条标号负结果（N-23 至 N-28），同样全部在册。

**主结果四：把纪律变成跑不过就报错的工件。** 态合法性从诊断升为盘上注册表（1,028 行）加同体守卫（合法子集 < 5 抛 `RedoxGateRefusal`，**不返回 None**），引用登记表的 10 行标记全部由守卫给出而不是手写；端点判等容差冻结为 1e-12（发布值与现场复算值最多差 2 ulp）；四通道噪声地板（0.4737 / 0.4903 / 0.5828 / 0.3695）接进显示层。三条曾被判为"设计缺陷"的判据被改法救回，且救回的是**问法**而不是数据：反解预算给出 tau=30 上 `alpha* = 0.06`（10 条推荐守住 precision ≥ 0.90；tau=15 上反解为空，照实判否）；零命中的绝对阈值换成相对判据（十分位比 **0.6518**，p = 0.000）加指纹盲区判据（26 对，其中 4 对绝对 Δε ≥ 5）；比值判据在五个干净阶梯上给出 **21.04 / 13.71 / 8.09 / 4.18 / 7.27** 倍，而 AUC30 极差全部 < 0.02。

**主结果五：「缺的那一维」是分子间关联。** 结构-only 的 1-近邻只有 R² **0.2503**；指纹相似度与标签差的秩相关只有 **−0.0607**（z = −2.1630，p = 0.0260），而"很像但差很大"的对数是 **0**；Kirkwood-Onsager 的相对取向相关因子在给体域对非给体域的中位数比是 **2.5016**（z = 4.076，p = 0.0060），高介电族子群比 **15.650**。三者同向指向同一句话：**单分子描述符传不了分子间关联**。第三个轨道与偶极外部层（QM9）给出同一种"排序学会、量级学不会"的签名：间隙 ρ 0.8856 而中位数比只有 0.7058；偶极偏离的主因不是构象自由度（刚性域绝对 Δμ 中位数 0.4442 D 对柔性域 0.4205 D，**判否**），而是约 **0.39 D 的系统偏置**。
