# W33-A：态合法性前置门禁 + 拒答队列 + 门禁后的还原轴排序重读

**性质**：后验重建（只读四张冻结表），**不占主记分牌 shot**（累计仍 19）；不重跑 xTB / ORCA、不拟合模型、不联网。

## 0. 一句话（全部由数据推出）

- **门禁挡掉的是多数**：气相合法集 52/246（21.1%）；通过率随介电常数非降（21.1% -> 62.6% -> 62.6% -> 65.4%）。
- **EA 条款不能单独当门禁**：气相「不束缚签名」只放过 53/246，而 EA>0 会放过 151/246 —— 差 39.8 个百分点。GFN2 的 dSCF EA 在阴离子不束缚时仍常为正。
- **门禁后 tau_b 全线下降**（最大跌幅在 benzaldehyde：0.1820）⇒ 原先的高 tau_b 里有一部分是「不束缚态同向漂移」造出的假一致。
- **配对锚点上的合法行数：GFN2 1/22、ORCA 0/22** ⇒ 那个 +0.835 / -0.602 的跨层级对比，本来就是在（几乎全部）不合法态上算的；ORCA 气相合法子集为 0，本轮按预注册判为**不可判定**，不引用 -0.602 作为该层读数。
- **判否登记**：H33e 判否 —— 预注册猜「两层裁决不一致占多数」，实测两层在这 22 个锚点上高度一致（一致率 95.5%）；层级依赖体现在「合法子集不够读数」，而不是「裁决互相矛盾」。

## 1. 门禁规则（预注册写死，见 `probes/w33_bound_state_gate_prereg.json`）

- `geom`：阴离子态 SCF/几何完好（`<medium>_anion_status == 'ok'`）
- `homo`：阴离子 HOMO < 0（等价于 `anion_unbound_<medium> == 'no'`，阈值 0.0）
- `ea`：绝热电子亲和 > 0（`ea_<medium>_eV > 0`）
- **合法集 = 三条款之交**；其余进拒答队列并记明理由；合法子集 < 5 的层级判为**不可判定**。

## 5. 判据（H33a–H33f）

- **H33a 成立**：门禁必要性：气相 EA 条款通过率与 HOMO 条款通过率之差（单用 EA 会多纳入的不束缚态占比）（读数 0.398374 对阈值 0.300000）。
- **H33b 成立**：层级依赖：ORCA 气相合法子集规模（< 5 ⇒ 还原轴在该层判为不可判定）（读数 0.000000 对阈值 5.000000）。
- **H33c 成立**：介质效应：门禁通过率随介电常数非降（取相邻步长最小值）（读数 0.000000 对阈值 0.000000）。
- **H33d 成立**：读数改变：门禁前后 tau_b 差的绝对最大值（读数 0.182004 对阈值 0.100000）。
- **H33e 判否**：跨层级裁决不一致：配对集上「GFN2 合法且 ORCA 不合法」的占比（读数 0.045455 对阈值 0.500000）。
- **H33f 成立**：拒答规模：气相拒答率（读数 0.788618 对阈值 0.700000）。

## 7. 口径与边界

- 四张输入表逐位只读并记 sha256；不重跑 xTB、不重跑 ORCA、不装依赖、不联网。
- 拒答不是缺失值：拒答 = 「在本层不可宣读」的明确结论，不得插补、不得赋伪值、不得静默丢弃。
- 跨层级只在配对集上比裁决一致性，不把两层的数值结果混在同一张记分牌上。
- 不改 METRIC_NAMES、不新增特征列、不动四个冻结读数与 ε 主记分牌。
- 若 ORCA 合法子集 < 5，报告必须写「不可判定」，不得引用 −0.602 作为该层的还原轴读数。
