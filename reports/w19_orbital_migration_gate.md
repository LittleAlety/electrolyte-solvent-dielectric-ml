## 三、迁移决策（结论）

**结论一句话**：**HOMO-LUMO 通道整体不过迁移门 ⇒ Batt-P30K 不升为主描述符源，仅作第二参考层；THEMol 保持现役主源不变，`no_reference_orbital` 键不优先补齐。**

理由（三条，逐条对应证据）：

1. **通道整体判据 = 三子通道全过才算通道过**：三通道中只有 homo 过门，且是边界过门（余量 0.0025 eV、16/49 折超门）；lumo 与 gap 均不过门。以「HOMO-LUMO 通道」为单位的迁移决策**必须**按最弱通道裁定——否则等于用一个边界通道的结果，去替换掉 lumo/gap 两个不过门通道的主源地位。
2. **替换的实际后果**：`no_reference_orbital` 键优先补齐，意味着把 Batt 的轨道能量写进我方分子。homo 可（带线性映射 + 标记），但 lumo/gap 不可——直接写入会把 Batt 的 **sd 0.3110 eV** 近常数 LUMO 列当成目标值，属**静默切换**，正是计划书禁止的动作。
3. **计划书分支字面**：「不过门 → 查明分歧源（方法学/标识符/构象），Batt-P30K 仅作第二参考层」——本件落在该分支。

**homo 的有限许可（带条件，不静默）**：homo 通道判 `usable`，允许作为**带线性映射的第二参考层**使用；写入任何池前必须显式携带 `cross_level` 与映射参数标记，且不得与 THEMol 气相值直接混比。

**THEMol 角色**：**不降级**。THEMol（GFN2-xTB 气相单点）继续是我方分子轨道量的现役主源；Batt-P30K 是其**第二参考层**（homo 可用、lumo/gap 仅参考）。

## 五、为什么 lumo 的留一 MAE 0.1984 **不得**升 `usable`

| 检查 | 读数 | 含义 |
| --- | --- | --- |
| 留一 MAE | 0.1984 | 表面 < 0.35，看似过门 |
| 常数基线（留一） | 0.2089 | 目标本身近乎常数时，什么都不学也能到该量级 |
| 相对 skill | **0.0504** | 相对常数基线只赢 5.0% → 迁移能力近零 |
| OLS 斜率 | **0.0550** | 近乎水平 → 预测几乎不随输入变化 |
| Batt `lumo` 列 sd | 0.3110 eV | 目标列本身离散度极小，MAE 低是**目标性质**、不是**映射能力** |

**裁定**：lumo 的低 MAE 是**空读数（empty reading）**——它来自目标近乎常数，而非来自 Batt ↔ 我方之间的可迁移关系。因此即便 MAE 0.1984 ≤ 0.35，也**不得**升 `usable`；E3 是双条件门，**r 0.4663 < 0.80 的失守是决定性的**，且相对 skill 0.0504 不构成「迁移能力」证据。
