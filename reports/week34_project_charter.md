## W34-B：R6 的配对重抽分辨率审计

**问题**：R6 说「氧化轴只动 −0.043、还原轴从 +0.835 翻到 −0.602」。还原轴的翻号显然很大；但**氧化轴的 −0.043 到底可不可分辨**？n = 22、没有区间、没有 σ——这个「不敏感」的结论此前从未被分辨率检验过。

**做法**（全部零新算力，只读两张冻结表）：

1. 按 `w24_3_posthoc.level_crosscheck` 的同一口径重算 22 个配对化合物的四条 τ_b（GFN2 氧化/还原、ORCA 氧化/还原），四个复现锚必须**逐位命中**，否则拒绝出报告。
2. **配对 bootstrap**（重抽单位 = 化合物，B = 4000，种子跑前写死 20261003）：给出 `Δτ_ox = τ_ox_orca − τ_ox_gfn2` 与 `Δτ_red` 的 95% 分位区间与跨 0 占比。
3. 与**独立地板**对照：`sqrt(2)·exact_sd(22)`（精确零分布，W33-B 工具）给出「若两条排序相互独立，n = 22 能分辨的最小 Δτ」；配对设计若有效，其区间宽度应**显著小于**该地板。
4. **叠加 W33-A 门禁**：登记配对集上的合法行数（GFN2 / ORCA），与 W33-A 逐位一致。

**可证伪预测（写死）**：

- **H34g**：还原轴 `Δτ_red` 的 95% 区间**不跨 0** ⇒ 翻号是可分辨的真效应。
- **H34h**：氧化轴 `Δτ_ox` 的 95% 区间**跨 0** ⇒ 「氧化轴对层级不敏感」在 n = 22 下**不可分辨**，正确表述是「未检出差异」，而不是「无差异」。
- **H34i**：配对设计的区间半宽 < 独立地板（配对确实降方差）。
- **H34j**：配对集门禁合法行数 = W33-A 的 1/22（GFN2）与 0/22（ORCA）。

**H34h 是本轮唯一可能有争议的预测**：若区间不跨 0，则「不敏感」成立、我的改写作废，照实登记判否。

## 口径与边界

- 输入表逐位只读并记 sha256；**不重跑 xTB、不重跑 ORCA、不装依赖、不联网**；全轮零新算力。
- **拒答不是缺失值**：守卫抛错是「在本层不可宣读」的明确结论，调用方不得捕获后插补、赋伪值或静默跳过。
- 交叉层级只在配对集上比裁决一致性，不把两层的数值结果混在同一张记分牌上。
- bootstrap 只在 **22 个配对化合物**上重抽，不外推到 246 普查；区间是**该配对设计**下的分辨率，不是全域噪声地板。
- 不改 `METRIC_NAMES`、不新增特征列、不动四个冻结读数与 ε 主记分牌。
