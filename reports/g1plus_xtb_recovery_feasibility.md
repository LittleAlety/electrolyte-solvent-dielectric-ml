## 一、结论先说

| 问题 | 判定 | 依据 |
| --- | --- | --- |
| 多片段起始几何的重叠能不能消除？ | **能** | 上一轮：逐片段打包把跨片段最短距离从 0.000–0.840 Å 抬到 3.000–4.328 Å |
| 三个离子对能不能让 xTB 正常收尾？ | **能**：4 个协议被冻结运行器对三者全部接受，其中 3 个同时几何全部收敛 | 本轮第二节 |

**一句话**：障碍是**技术上可解**的，但不是**协议中立**的。把 4 行救回来必须换掉整个特征表的计算口径，
因此它不是一次免费的数据增益，而是一次会让所有基准数字改动的迁移。

## 二、三个离子对：冻结协议失败，但有 4 个协议对三者全部被接受（其中 3 个几何全部收敛）

### 2.1 先纠正上一轮探针的一个判据错误

上一轮的诊断探针把「成功」定义为 stdout 里出现 `normal termination of xtb`，因此把一批 run 记为未正常终止。
**这个判据是错的**，有两条独立证据：

1. xTB 6.7.1 把 `normal termination of xtb` 打印到 **stderr**；实测 stderr 逐字为 `b'normal termination of xtb\r\n'`，而 stdout 不含该串（0 命中）。
2. 冻结运行器本身并不依赖该串。`scripts/run_xtb_physical_features.py:279-285`：
   stdout 里没有标记串时，只要存在 `.xtboptok` 哨兵文件，它就把标记串**补进文本**再解析，然后照常要求四个特征全部可解析。

抽一个冻结成功产物核对：`data/interim/xtb_features/AFBPFSWMIHJQDM-UHFFFAOYSA-N/xtb.out`（42 614 字节）
**不含** `normal termination of xtb`，但 `.xtboptok` 与 `xtbopt.xyz` 都在 ⇒ 冻结管线判它为成功。
所以本轮探针改用**冻结运行器的真实判据**：

> `exit code == 0` **且** `xtbopt.xyz` 存在 **且**（stdout 有标记串 **或** `.xtboptok` 存在）**且** 四个特征全部解析成功。

（三个离子对与三个对照分子的原始 argv 都记在证据 JSON 里，可逐条手工重放。）

### 2.2 完整策略矩阵

起始几何一律是**逐片段打包后**的构型（上一轮的修法）；每格写「冻结运行器是否接受 / 几何优化是否收敛」。

| 协议 | 1,3-二甲基咪唑鎓二甲基磷酸酯 | 1-丁基-3-甲基咪唑鎓 PF₆ | 1-丁基-2,3-二甲基咪唑鎓 PF₆ |
| --- | :---: | :---: | :---: |
| 冻结口径 `--opt --gfn 2 --chrg 0 --uhf 0` | ✗ exit 128 | ✗ exit 128 | ✗ exit 128 |
| `--etemp 1000` | ✓ / geoopt ✗ | ✓ / geoopt ✓ | ✓ / geoopt ✗ |
| `--etemp 5000` | ✓ / ✓ | ✓ / ✓ | ✓ / ✓ |
| `--acc 5.0` | ✗ exit 128 | ✗ exit 128 | ✗ exit 128 |
| `--etemp 5000 --acc 5.0` | ✓ / ✓ | ✓ / ✓ | ✓ / ✓ |
| `--alpb acetonitrile` | ✓ / ✓ | ✓ / ✓ | ✓ / ✓ |
| GFN-FF 预优化 → GFN2 | ✓ / ✓ | ✗ exit 128 | ✓ / ✓ |

读法：**仅放宽 SCC 精度阈值（`--acc 5.0`）不管用**；真正起作用的是改变电子结构处理方式的几项。
有两个**单项**改动都让三个分子**全部**既被接受、又让几何优化收敛：
`--etemp 5000`（梯度范数 0.00044–0.00056 Eh/α）与 `--alpb acetonitrile`（0.00040–0.00070 Eh/α），都低于 1.0e-3 的收敛阈值；
`--etemp 1000` 虽被接受，但有两个分子的几何优化**没收敛**（梯度 0.0018 / 0.0051 Eh/α），属于「运行器接受、物理上没到位」。

### 2.3 顺带否掉的一条捷径

`--acc 5.0` 单独使用仍然 exit 128，说明这三个体系的原始失败**不是**「SCC 阈值太严」，
而是电荷分离体系在默认 300 K 电子温度下的 SCF 行为本身。

## 三、五羰基铁：至少找到 4 个「既能净化、又能嵌入」的结构

上一轮的结论是「单纯换 SMILES 不够」。本轮把候选空间系统性扫了一遍，**这个结论需要上调**：存在可行写法。

下面是本轮**已记录**的候选，**不构成穷尽性证明**——两个独立扫描各自又补充了同族写法，说明这一族里还有等价成员。

| 候选 | 净化 | 片段数 | Fe–C 键 | 默认嵌入 | 随机坐标嵌入 |
| --- | :---: | :---: | :---: | :---: | :---: |
| 冻结库存值 `[C]=O.[C]=O.[C]=O.[C]=O.[C]=O.[Fe]` | ✓ | **6** | **无** | 0 | 0 |
| `O=C=[Fe](=C=O)(=C=O)(=C=O)=C=O` | ✓ | 1 | 5×双键 | **-1** | **-1** |
| **`[Fe](<-[C]=O)(<-[C]=O)(<-[C]=O)(<-[C]=O)<-[C]=O`** | ✓ | **1** | **5×配位键** | **-1** | **0** |
| `O=[C]->[Fe](<-[C]=O)(<-[C]=O)(<-[C]=O)<-[C]=O`（RDKit canonical） | ✓ | 1 | 5×配位键 | -1 | 0 |
| `[Fe]([C]=O)([C]=O)([C]=O)([C]=O)[C]=O` | ✓ | 1 | 5×单键 | -1 | 0 |
| `[Fe](<-[C-]=[O+])(<-[C-]=[O+])(<-[C-]=[O+])(<-[C-]=[O+])<-[C-]=[O+]` | ✓ | 1 | 5×配位键 | -1 | 0 |
| `[Fe](C#O)(C#O)(C#O)(C#O)C#O` | ✗ | — | — | — | — |

最优候选实测：分子式 `C5FeO5`、总形式电荷 0、单片段、5 条 Fe–C 键（键型 `DATIVE`，方向 C→Fe），
Fe–C 键长 2.0914–2.1328 Å；默认 ETKDG（seed 42）返回 -1，**打开 `useRandomCoords=True` 后返回 0**。

关键点：可行的写法把 CO 配体写成**括号化的 `[C]=O` / `[C-]=[O+]`** 再配 `<-` 配位键，绕开了中性 `C#O` 里 O 三价导致的净化错误；
上表里 `[Fe](<-[C-]=[O+])(...)`（电荷分离写法）的实测键长与 `[Fe](<-[C]=O)(...)` **逐位相同**（2.0914–2.1328 Å）。
这是一个**建模选择**——它表达的 Fe–C 配位作用是库里的 `InChI=1S/5CO.Fe` 根本写不出来的。

## 四、决定性对照：这些协议会移动特征，而且移动得不一样

「能被运行器接受」不等于「能和已冻结的 242 行并列」。本轮拿三个**在冻结协议下本来就成功**的分子做对照，
从**各自的冻结起始几何**出发，只改一个标志位（`--etemp 5000`），比较解析出来的四个特征：

| 对照分子 | 偶极变化 | HL-Gap 变化 | 极化率变化 | 总能量变化 |
| --- | ---: | ---: | ---: | ---: |
| 丙-1-醇 | **0.0000%** | 0.0000% | 0.0000% | 0.0000% |
| N-甲基苯胺 | 4.25% | 0.93% | 0.0004% | 0.0046% |
| **三乙基戊基铵 双(三氟甲磺酰)亚胺（离子液体）** | **40.36%** | **82.78%** | 0.0043% | 0.0657% |

最大相对位移 **82.8%**，出现在**同类体系（离子液体）的 HL-Gap** 上；
而丙-1-醇的偶极与 HL-Gap **完全未变**，极化率与总能量只有 **1e-8 量级**的相对漂移（四舍五入后显示为 0.0000%）。
需要注意：这里只有**一个**离子液体对照，所以「漂移集中在离子液体这一类」是**本轮的观察**，不是已证的一般规律。

这三点合起来排除了「加个常数校正」的退路：

1. 位移**不是全表统一的**——同一个标志位对丙-1-醇几乎无影响，对离子液体却把 HL-Gap 抬了 82.8%；
   因此**全表统一的「每个特征加一个常数」式校正**被排除。
2. **但这一步只排除到那儿为止**：按分子类别分别校准、分层建模、或给这 4 行单列一个补偿项，本轮**都没有排除**；
   而这类做法本身就要引入新的假设与新的泄漏风险，属于方法学决策，不是免费修正。
3. 该离子液体对照在 `--etemp 5000` 下**几何优化还不再收敛**，说明偏移伴随物理状态改变，不只是数值噪声；
   这一条同样只由单个对照支撑。

## 五、判定与建议

**判定：这 4 行技术上可救回，但不能在原地救回。**

- 只对这三行改用 `--etemp 5000` 或 `--alpb acetonitrile`（这两者对三者都既被接受又几何收敛；
  GFN-FF 预优化只对 2/3 有效，不能作为三者统一替代）⇒ 特征表里会同时存在两套电子结构口径，
  而**在本轮唯一一个离子液体对照里**漂移幅度最大的正是新加入的这一类 ⇒ 会引入一个**按分子类别分布的系统偏差**隐患。
- 对全部 246 行改用同一新口径 ⇒ **不能假定逐行逐特征都会变**：丙-1-醇的偶极与 HL-Gap 已实测**完全未变**，
  极化率与总能量只有 1e-8 量级漂移；但全表口径迁移后仍须**整表重跑并重钉基准**——
  236 行拟合集、全部基准数字、全部骨架/共形结果都必须重跑后重新确认。

所以建议：**v0.3.14 若要落地，必须定位为一次整表协议迁移，而不是一次「补 4 行」的增量修复**；
并且迁移前要先决定——是接受全表重跑后的新基准，还是保持 236 行现状不动。本轮不替项目做这个决定。
