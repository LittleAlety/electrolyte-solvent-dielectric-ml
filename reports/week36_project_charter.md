## 2. W36-A：端点规则正式化

**规则条款 7 条**（`data/processed/w36_endpoint_rule_registry.csv`）：R1 端点定义、R2 锁定种子集 `42/1234/2026/31337/7`、R3 每种子折数 **10**（RepeatedKFold 5×10）、R4 稠密 13 列块默认 `max_bin=128`、R5 **端点判等容差 1e-12**、R6 冻结读数表条目策略、R7 四个冻结读数。

**复算符** `endpoint_of(rows, arm)`：种子集或折数不符即抛 `SeedSetDriftError`——端点不允许在漂移的网格上宣读。

**复算结果**：六张逐重复表、**49 个臂**；其中 **26 条已发布端点全部在 1e-12 内复现**（最大差 `2.220446049250313e-16` = 1 ulp）；3 个**描述性臂**（`w28` 的 `lever4_morgan_frozen` / `lever4_morgan_retuned` / `lever4_physical_retuned_shuffled_target`，每种子仅 1 折）标注为「不适用」并且**没有发布值**。

**本轮最重要的发现**：把规则写下来才暴露——发布值与独立复算的 `fmean` 最多差 **1–3 ulp**。因此「端点判等」**不能**写成逐位字符串相等，必须是**容差**。这是 R5 存在的全部理由。

**判据 H36a1–H36a5 全部成立。**

## 3. W36-B／C：噪声地板显示层 + 多保真度准则

**W36-B（显示层）**
- 四个通道的 s0 与四个 Δτ 档（0.05 / 0.10 / 0.15 / 0.20）的所需 N 落进 `probes/artifacts/w36_channel_noise_floor.csv`；所需 N 由 W33-B 的精确零分布工具复算，与已发布的 `w33_kendall_null_budget.csv` **最大差 0**。
- `*_repeats.csv` 共 **52 张**：**51 张**映射到通道并带上噪声地板，**1 张**（安全通道）显式标注「未映射」。
- **被冻结的表一个字节都没改**（生成前后逐文件 sha256 断言相等）。加列会改字节、破坏 AF-12 坐标，所以噪声地板走**旁挂附表**，入口是 `probes/artifacts/w36_channel_dashboard_v2.csv`。

**W36-C（准则）**
把 W32-A 的单调关系写成可执行的四步：

1. 量低保真代理的排序保真度缺口 `gap = 1 − tau_b_full`；
2. `s0_hat = 0.30758114075296145 + 0.33317352371160197 · gap`（R² = `0.4437345881956626`）；
3. 代入 `required_n(s0_hat, N_pop, Δτ)` 得该代理可分辨 Δτ 所需样本量；
4. 手上 N 低于该线 ⇒ 该代理在这个样本上**不可分辨**，不得据其排序下结论。

**复现**：Spearman = `0.8058119658119658`（与 W32-A 的 R2 逐位相同，26 条序列）。**外推校验**：用缺口预测的 N 对实测 s0 的 N，四个通道**全部一致**，相对误差中位 **14.6%**（最大 28.0%，在黏度通道）。

**判据 H36b1–H36b4、H36c1–H36c4 全部成立（8/8）。**
