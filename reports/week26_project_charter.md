## 3. 口径纪律（本轮全程生效）

- 图层级必须同句声明：**本仓 = GFN2-xTB / ddCOSMO / 242 分子 / 刚性气相几何**；**v6 = r2SCAN-3c / CPCM 裸扫描 / 18 分子 / 10 台阶**。跨层级只比**函数形式与量级**，绝不比绝对值。
- ddCOSMO 是导体样屏蔽模型，ALPB 是线性响应近似，CPCM-X 是两者的混合修正；三者不是同一物理近似，W26-3 只报**差**，不报谁更对。
- 阴离子在气相常常**不是束缚态**，其 SCF 收敛到的是驻点或直接失败；W26-2 的闸门判据只用总能量差，不依赖阴离子轨道符号。
- 本轮不引用任何 Reaxys 数值；THEMol（CC BY-NC 4.0）不入交付包；Batt-P30K（MIT）只作参考层。
- 对 W24-1 的任何修正都在报告里显式登记为「W26 对 W24-1 的再解释」，**不改 W24-1 已冻结的表**。

## 5. 预注册修订 2（生产运行之前）

第一次 8 分子冒烟暴露两处**定义缺陷**，修订发生在 242 分子生产扫描之前：

1. Born 拟合把首点错锚在 ε=2 而不是气相点，导致离子态 R² 假性塌到 0.705（修好后为 0.99994）。
2. 气相锚点按原文口径必然为假——w21.parse_arm 读的是 xTB --opt 日志里的**首个 ISCF 块**（输入几何），不是优化后几何。

改动清单：

- H1b 明确为 Born 腔残余 |C_fit|/ε 在 ε=200 的取值（与 W24-1 同口径）；H1c 保持实测再走量 |ΔE(1000) − ΔE(200)|；H1d 的「残余」明确为 |C_fit| − |ΔE(ε)|，带内 ε ∈ [20, 1000]。
- H1b / H1c / H1d 的裁决集合明确为**离子曲线**（阳离子 + 阴离子），三态合并值并列报出。
- H1e 只在**离子对**上取中位（中性对按构造恒为 0，否则会把判据稀释成必然成立）。
- H1f 拆成 **H1f**（原文口径：优化几何单点对冻结层）与 **H1g**（冻结层实际口径：--opt 日志首个 ISCF 块对冻结层）；**H1g 是本轮的复现性闸门**，取代 §2 里「H1f 若破则本轮作废」的表述。
- H2a 的分母明确为「气相电子亲和 ≤ 0（未束缚）的分子」，分子为这些分子中在网格内出现 EA > 0 的占比。

**没有任何阈值被移动**：0.99 / 0.020 eV / 0.015 eV / 0.35 / 0.05 eV / 0.50 / 40.0 / 0.15 eV 全部与修订 1 相同。修订依据逐条记在 `probes/w26_dielectric_law_prereg.json` 的 `revision_note` 与 `smoke_pilot_evidence` 里。
