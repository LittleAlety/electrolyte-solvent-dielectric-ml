# W40-C Onsager 域规则精化 + 偶极双 mu 读数化（后验读数，0 shot）

定义 `L(eps) = (eps-1)(2eps+1)/(9eps)`，`x = mu^2 / V_m`，
`g_rel = (L/x) / median_{非给体域}(L/x)`。非给体域的中位数恒为 1（定义，不是结果）。
域划分是**跑前写死的机械规则**，不按 eps 大小挑样本；本件不拟合模型、不新增特征列。

## 1 口径精化：从 hbd 列到显式可给体质子

- 旧口径（W38-C）：table hbd == 0 判为非给体域（A），hbd >= 1 判为给体域（B）（W38-C 口径，继承 RDKit Lipinski donor）。
- 新口径（本件）：donor_h >= 1 判为给体域（B），否则非给体域（A）。donor_h = 分子里满足以下全部条件的氢数：(1) 氢连在 N / O / F 上；(2) 该杂原子形式电荷 <= 0（正电杂原子的氢排除，如 [NH3+]）；(3) 不是酰胺 N-H（N 匹配 [NX3][CX3]=[OX1]）。S-H 不计（任务规定只算 N/O/F，属已登记规则边界）。规则只读结构、不读 eps；跑前写死，不按 eps 大小挑样本。
- 新旧在 241 行上的 RDKit NumHDonors 一致率 = 1.0000（表内 hbd 列与 RDKit 重算一致；差异全部来自规则本身，不是数据不一致）。
- 新口径域规模：A 非给体域 n = 160；B 给体域 n = 67（旧口径为 159 / 68）。

### 2.1 水的归属为什么在旧口径下错了

- 水的 SMILES 是 `O`。RDKit 的 `Descriptors.NumHDonors(H2O)` 返回 **0**（Lipinski 给体定义按重原子环境计数，水被排除在外），名册 `hbd` 列同样是 0，于是水被机械地放进「理应 g 接近 1」的非给体域 A。
- 新规则直接数氢：水的两个 O-H 都满足「连在 O 上、杂原子形式电荷 0、不是酰胺 N-H」，所以 `donor_h = 2`，水被判入给体域 B。
- 数字后果：水在旧口径下的 g_rel = 2.218704（相对旧 A 域中位数），在新口径下 g_rel = 2.2506，相对新 A 域中位数 1.873e-05。
- 注意这条纠正的**方向**：旧口径把水放在 A 域，抬高的是 A 域的中位数分母、同时把水从 B 域剔除；改正后高介电族的域间比从 15.6504 降到 13.4044，即旧口径**高估**了域分离（H40c6）。所以这条修正是把读数变得更保守，不是更好看。

## 5 偶极质量审计收口：约 0.39 D 系统偏置的敏感性

- 从 W39 对照层重算的签署差（QM9 减本地）中位数 = -0.391400 D（|delta| < 1 D 的 90 个化合物），与 W39 登记值 -0.391400 一致。
- 校正口径：`mu_corr = dipole_D + 签署差中位数`（即 mu 减去约 0.3914 D）；`mu_corr <= 0` 的行（16 行，多为近零偶极烷烃）在该变体里直接丢弃，不插补。
- 校正后域间比 = 3.113253（未校正 2.581713），相对变化 = 0.205886。
- 结论方向不变（仍远大于 1.5），但幅度变化超过 10%：因为 `g_rel` 是 `1/mu^2` 变换，把 mu 的加性偏置放大成乘性变化。这就是 H40c10 判否的实质。

## 7 边界（必须与数字同句引用）

- **规则边界 1（S-H）**：任务规定只算 N / O / F，所以硫醇的 S-H 不计给体，2 条硫醇（1-Butanethiol、1-Pentanethiol）由给体域移出。这是规则选择，不是数据错误。
- **规则边界 2（正电杂原子）**：正电杂原子上的氢被排除，涉及 1 条（ethanolammonium nitrate，[NH3+] 的三个氢）；该化合物仍有 O-H，域不变。
- **规则边界 3（互变异构敏感）**：名册里甲酰胺写作 `N=CO`、N-甲基乙酰胺写作 `CN=C(C)O`，都是亚胺醇式，其给体由 O-H 提供；若按 RDKit 标准互变异构体归一为酰胺式 `NC=O` / `CNC(C)=O`，则两者的 N-H 全部被酰胺条款排除，由给体域移出（N-methylacetamide、formamide）。归一后域间比 = 2.472579，结论方向不变。**这是本规则最脆的一处**：本名册书写下酰胺条款零作用（0 条），所以「酰胺共振」这条物理假设在本件里其实**没有被检验**，只被登记为边界。
- **统计量病态**：不加 mu 门槛时 `L/x` 在 mu 趋近 0 处发散（烷烃把排名占满）。因此域间比较只用**中位数**，双 mu 秩比较只用 **mu >= 1 D** 的子集；g_rel 的绝对排序不得当物理结论。
- **g_rel 是无量纲相对量**：单位被斜率吸收，只可做域间比较，不得与文献 g 绝对值对照。
- **水的读数不是量级证据**：水的新口径 g_rel = 2.2506 低于给体域中位数 2.5817（H40c11 判否）；偏置校正后为 2.7378，仍低于校正后的给体域中位数 3.1133。所以「水被错分域」是**分类**纠正，不能读成「水的残差极端大」。
- 不拟合模型、不新增特征列、不触 eps 主记分牌；不占 shot（累计仍 19）。
