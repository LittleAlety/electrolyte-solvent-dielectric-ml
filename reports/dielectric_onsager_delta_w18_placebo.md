## 二、单位换算自检（先证没有算错，再看结论）

解析项按本仓规范式 `src/electrolyte_ml/xtb_features.py::onsager_dielectric_estimate` 复刻：

- 高频介电常数（Lorentz–Lorenz）：`n2 = (1 + 2q) / (1 - q)`，其中 `q = N_A * alpha / (3 * V_m)`
- 反应场项：`A = N_A * mu^2 / (9 * eps0 * k_B * T * V_m)`
- 解 `(eps - n2)(2 eps + n2) / (eps (n2 + 2)^2) = A` ⇒ `eps = (L + sqrt(L^2 + 8 n2^2)) / 4`，其中 `L = n2 + A (n2 + 2)^2`

**换算链（本枪第一次算错过的地方）：** molecular_volume_A3 是**单分子**体积（A^3），不是摩尔体积：本枪第一版直接把该列当 V_m 用，导致 q 被放大 N_A 倍、n2 落到 -2、解析项全塌成 1.0。正确换算是 V_m = molecular_volume_A3 * 1e-30 * N_A（m^3/mol）；而极化率密度 q = polarizability_A3 / (3 * molecular_volume_A3) 里 N_A 正好抵消。
