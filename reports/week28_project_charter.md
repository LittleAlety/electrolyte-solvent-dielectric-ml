# Week 28 立项章：稠密块 XGB 超参的嵌套重调（第 1 枪）与固定档位阶梯（第 2 枪）

- 触发：W27 交付（87b4360）§9 的自然入口 ——「给稠密配置预注册一次 inner-fold 超参重调（这是唯一可能把单表示跨种子端点 0.5861142332208197 推过 0.60 的单杠杆），并在同容量对照下重测响应块」。
- 性质：**零新算力的超参工程 + 主记分牌两枪**。不跑 xTB、不装新依赖、不联网；全部由盘上已有产物派生。
- 与 W27 的关系：W27 把宽度惩罚定了价（13 列响应块掉 0.096956，同宽度行打乱块仍掉 0.006099，超过 0.005 惰性线），并明确写下「余下的 0.0061 只能是拟合对宽度的反应」。W28 就是去追这 0.0061：**冻结超参是不是为 2048 列稀疏 Morgan 定的、在 13 列稠密块上欠拟合**。
- 主记分牌 shot：**2**（累计 15，W21–W26 各 0、W27 计 1）。四个冻结读数（0.4091179943351143 / 0.4766400383507876 / 0.5861142332208197 / 0.6216672295270079）未动。

## 1. 为什么这是唯一没被打死的单杠杆

截至 W27，本仓自己的侦察已经证否了这些路径：换拟合器（GPR 0.2313、MLP -0.172）、网络叠加/bagging（+0.00175 inert）、外来化学空间（NBS-514 → 0.3809 反噬）、杂类锚点（shot 15 → 0.5102 反噬）、受限源（红线）。**「不同网络叠加」这条已被判决**，不必再纠缠。

剩下的机制读数指向同一处：冻结超参 `max_depth = 2` / 200 树 / `lr = 0.05` / `max_bin = 64` 是当年为 **2048 维稀疏 Morgan 指纹**定的；胜出的 Physical 单表示只有 **13 列稠密特征**，深度 2 意味着**每棵树只有 4 个叶**。这不是「换个模型」的重开一枪，而是「同一个模型、同一族特征、把容量参数按稠密块重新标定」。

## 4. 第 1 枪的选择规则（嵌套，跑前冻结）

- 每个外层折内部，用 `GroupKFold(n_splits=3)` 按化合物把**该折的训练行**切成 3 个内层折；
- 网格每一档用**三个内层留出的合并 R²** 打分（先拼接靶值与预测，再算 R²）；
- 赢家在整个外层训练集上**重拟合**，再预测外层测试行；**外层测试行从未被选择过程看到**；
- 平局取网格里更早的一档（`np.argmax` 的语义），整个过程确定可复现；
- 内层折不引入随机性（`GroupKFold` 无 `shuffle`），因此「随机性」只来自外层折的种子集。

真正被预注册的是**判据**而不是「重调一定有效」：H28d 只要求增量为正，H28e 才要求过 0.60。若内层选择在噪声里乱挑，读数会塌在 H28d 上，这正是要测的东西。

## 5. 第 2 枪的阶梯规则（为什么必须与第 1 枪分开）

「**有没有更好的固定档位**」与「**选择器能不能挑中它**」是两个不同的事实，必须分开记。阶梯把网格每一档在**完全相同的折**上各拟合一次，没有任何选择、没有任何一步看过测试行（除了把它预测出来），所以每一档都是一个诚实读数。如果阶梯存在过 0.60 的档位而嵌套选择上不去，结论就只能是「选择器坏了，不是网格不够」——这是一条对**方法论**有价值的读数，而不是对模型的。

## 6. 口径纪律（本轮全程生效）

- **池与掩码逐字复用冻结主记分牌**：2391 行池、评分 457 行 / 97 化合物、训练掩码 full_base、`splits_for(seed, ...)`（5 折 × 10 重复，GroupKFold by InChIKey，masked_splits + drop_thin_folds）、五种子 {42, 1234, 2026, 31337, 7} 逐字复用。
- **折任务的 `random_state` 是固定常量 42**（`dielectric_representation_ablation.SEED`），不是循环种子 —— 这是**冻结折任务的定义**，冒烟阶段一度按循环种子跑导致 4/5 种子对不上，改回常量后五个种子全部逐位复现。
- **缺行不插补**：响应块在名册之外的池行上留 NaN，交给 XGBoost 原生缺失值处理；不计算任何折内统计量、不丢弃评分行。
- **响应块无任何一列触及被测 ε**：块与 W27 逐字相同（同一 `build_block()` / `response_matrix()`）。
- 安慰剂只打乱**外层折内的训练靶值**（生成器 `default_rng([2026, repeat, fold])`，种子在预注册里冻结），测试靶值保持真实。
- **不改 `METRIC_NAMES`**（它驱动被锁 CSV 的表头）；AUC 走既有侧车路线。
- 图层级同句声明：本仓 = **GFN2-xTB / ddCOSMO 任意 ε / 刚性气相几何 / 242 分子**；母体论文 v6 = r2SCAN-3c / CPCM / 18 分子。跨层级只比函数形式与量级。
- 不引用任何 Reaxys 数值；THEMol（CC BY-NC 4.0）不入交付包；Batt-P30K（MIT）与 RX-392 / SolvFunc-87 只作参考层。

## 8. 冒烟证据与一次网格裁剪（阈值一个未动）

冒烟只跑 seed 42、每臂只跑 repeat 0（15 折），不写任何结论，只验证管线与测成本：冻结臂 13.3 s（15 折，第 0 折 0.634700）；重调臂 96.4 s（15 折，第 0 折 0.517082）；冻结(物理+响应) 10.9 s（第 0 折 0.447564）；重调(物理+响应) 96.1 s（第 0 折 0.443620）。

冒烟同时给出了一条**负向机制证据**：在 seed 42 的前三个外层折上同时算「每一档的内层选择分」与「每一档的折外 R²」，**三个折上内层 argmax 与折外 argmax 全部不一致**（d3 对 d4、d3 对 d2/n1000、d3 对冻结档）。内层选择分本身经常为负（-0.08 ~ -1.02），因为内层留出只有训练行的 1/3，R² 被少数极端 ε 化合物主导。这条读数**在跑之前就写进了预注册**，因为它是本轮最可能的失败模式。

网格按**成本与信息量**裁剪为 6 档（深度 2/3/4、树数 200/400、lr 0.05/0.02）：1000 树与深度 6 的档位既贵（每折 19 次拟合里最慢的两档）又不在内层选择里胜出。**判据、阈值、安慰剂规则、种子集、臂一条未动**，`thresholds_moved = false`。
