## 0. 这一枪买到了什么

框架 §3 Axis A 的 `P_2`（固定背景连续介质）自建仓起为空 —— 本仓此前**所有**轨道数都是气相单点。对电解液筛选而言这是错的量：决定氧化稳定性的不是气相 HOMO，而是溶剂化后的 HOMO。本臂用现成冻结 runner 把这一维补上，并把 Axis B 的 `C_1` 从「仅气相」升级为「气相 + 三档介质」。

**池与执行**：冻结 ε 名册 246 化合物 × 8 臂 = **1,968 次 GFN2-xTB**（xTB 6.7.1pre），实际跑满 **1968/1968**，挂钟 **681 s**（分子级 10 并发，单臂仍单线程）。8 臂 = 气相 free / 气相 Li⁺（回归锚）+ 2 态 × 3 介质；介质为 **ALPB 同一隐式模型**的三档 ε：thf (7.58)、benzaldehyde (18.0)、water (80.4)。

## 2. 两种「判否」性质完全不同（本件最值得记的一条）

- **自由态**：位移均值 **+0.032 / −0.053 / −0.038 eV**，而逐化合物标准差 **0.16–0.30 eV** —— 均值远小于离散 ⇒ 不是「符号相反」而是「**符号不成体系**」。把判否读成「溶剂没有影响」是错的。
- **Li⁺ 态**：HOMO 与 LUMO **同时上移约 3–4 eV**（+3.05/+2.95/+3.48 与 +3.43/+3.37/+4.20），216 个化合物 **100% 为正** ⇒ **符号被反转**：阳离子被极性介质稳定，轨道能整体抬升。预注册把中性分子的教科书符号写给了带正电的加合物 —— **0.0% 是预注册的错，不是数据的错**，照实登记，不改判据。

## 4. 质控、失败与边界（照实）

- Li⁺ 臂质控（判据与 W21 完全相同）：gas 236 intact / 1 loose / 2 dissociated；thf 234/5/2；benzaldehyde 224/**14**/2；water 225/**12**/2。介质让 Li⁺ 结合略松（q(Li) 中位数 0.703 → 0.732），与「溶剂竞争配位」一致。

- gap 与 v03 物理块一致性：自由态各档 r = 0.9992–0.9997；Li⁺ 态 r = 0.463–0.520（Li⁺ 态 gap 只有 2.6–3.3 eV，本就不该与自由态 gap 同量纲）。
