## 2.3 H3 判否 —— 均值自己就不单调（本 lane 最值得记的一条）

严格递增只有 **11/238**，但更要紧的是**通道均值本身也不单调**：`|mean dIP(thf)| = 1.9574` **大于** `|mean dIP(benzaldehyde)| = 1.7930`，而 `ε(thf) = 7.58 < ε(benzaldehyde) = 18.0`。⇒ 「位移随 ε 单调」在半经验 + ALPB 层面**不是普遍性质，连均值层面都不成立**；不得用「ε 越大位移越大」做外推。W23-1 在轨道通道上已见同一现象，本 lane 在**氧化还原通道**上独立复现。

## 2.4 H4 成立 —— W22 评审 A5 首次被实测支持

阴离子最高占据轨道能 > 0（「电子未束缚」签名）的占比：**气相 188/241 = 0.7801** → thf 86/242 = 0.3554 → benzaldehyde 87/242 = 0.3595 → **水 80/241 = 0.3320**。⇒ 气相 EA 在 **78%** 的化合物上根本不是束缚态，所加电子不在束缚轨道里，此时 −ε_LUMO 描述的**不是同一个物理量**。「还原轴结论只以有连续介质的层为载体」因此从**断言**变成**实测**。

## 2.5 H5 判否 —— 「量级偏 + 排序也没守住」

| 对比 | ρ | 平均有符号差 (eV) |
| --- | --- | --- |
| ip_gas | **0.3455** | +6.7770 |
| ip_thf / ip_benzaldehyde / ip_water | 0.4788 / 0.4667 / 0.4788 | +4.4814 / +4.6467 / +4.0654 |
| ea_water | **−0.2485** | +1.5841 |

判据是「`|偏差| ≥ 1.0 eV` **且** `ρ ≥ 0.60`」：量级那一半过得非常宽，**排序那一半没过**，因此判否。四点必须同时说：(a) 溶剂化让吻合度**单调改善**（0.3455 → 0.4788）但**从未越过 0.60**；(b) EA 侧连符号都是负的；(c) 参考层是**自由能约定**而本臂是**能量差**，6.78 eV 里含约定差，**不得**读成纯方法误差；(d) n = 10 只覆盖名册的 4.1%，属**极薄**外部对照。⇒ 诚实结论：**本层级不能替代 DFT 级 `P_1`。**

## 2.6 排序稳定性（R5）—— 一个干净的「近刚性平移」读数

12 条介质对比（IP/EA × 6 对对），`ρ` 全部 **≥ 0.94**（最低 0.9494 = ip gas→water；最高 0.9950 = ea thf→water），Top-10% 重叠 **0.83–1.00**；且 `gas → 溶剂` 的 `ρ` 系统低于 `溶剂 → 溶剂`。⇒ 换隐式溶剂主要是一次**共同平移**，内部次序基本守住 —— 与 lane 1 在轨道通道上的结论一致。

## 2.7 Koopmans 对照（R3）—— 偏移量随 ε 单调缩小

`IP_dSCF − (−ε_HOMO)` 均值：gas **+2.9463** → thf +1.0370 → benzaldehyde +1.1273 → **water +0.6671** eV；`EA_dSCF − (−ε_LUMO)`：gas **−3.2452** → thf −1.3322 → benzaldehyde −1.4056 → **water −0.9504** eV（秩相关 IP 0.8463→0.9156，EA 0.9492→0.9726）。⇒ dSCF 与 Koopmans 的差别主要是一个**近似常数位移**，而隐式溶剂**吸收了它的大部分**。这正是框架 §22.2（情形 B：数值变化大而排序稳定），只不过这次是在 **238** 个化合物上、而不是 18 个。

## 2.8 失败、重试与边界（照实）

- 失败臂 **45/2952（1.5%）**，全部落在离子液体（中性盐对）与金属羰基上；SCF 重试恢复 **13/45**，**性质为 post_hoc，不参与任何预注册读数**。
- **绝热 ≠ 垂直**：本臂三态各自 `--opt`；框架 §2.3 的 P1 是垂直三点法。两者不得混比，也不得与本仓历史 Koopmans 数值直接相减。
- **净电荷非零化合物单独统计**：本轮 246 条记录**全部**是净电荷为零的输入（离子液体以中性盐对形式入池），带电类分支样本为 0 —— 如实登记，不构成「跳过=通过」。
- 阴离子束缚签名只描述「最高占据轨道能的符号」这一件事；半经验层没有弥散函数，它**不是**束缚能的严格判据。
- layer 的列集合经过一次自查修剪：`cation_relax_*`（本臂从未测量垂直量）与 `d_ip_gas_eV` / `d_ea_gas_eV`（气相相对自身无定义）共 6 列被删除，layer 以 **94 列**重跑，读数逐位不变；测试里有一条断言钉死「不留声明了却从不填充的列」。
