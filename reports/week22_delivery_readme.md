## 1. W22-1（A3 + D1）：安全定理的因子 2 被证实，且界是紧的

命题：单格最大效应量 `A_axis = max_i |Δe_i|`，间距 `d = e_i − e_j` 受**两格**扰动 ⇒ `|Δd| ≤ 2·A_axis`，严格判据应为 `|d0| ≥ 2·A_axis`。

- `m=1`（现判据）**漏解**：平均 0.860%（最坏 1.294%），200/200 次实现均出现漏解。
- `m=2`（严格判据）**零漏解**：200 次 × 19,900 对全为 0。
- 界是**必需**的：`max|Δd|/(2A) = 0.99895`。
- 留一台阶前瞻（D1）：2Â 处漏判翻号 0 次、Â 处漏判 **1,382** 次（占 10,875 次真实翻号的 12.71%）；precision 0.99667 / recall 0.99998。
- **代价**：1,176 对、`A=0.152 eV` 下安全 pair 由 1,013（86.14%）降到 874（74.32%）（−139 对，相对缩水 13.72%）。
- **边界**：扰动无界时（Normal 臂每轮约 9.17 个分子 `|Δe|>A`）`m=2` 仍有极小漏解（均值 1.14e-4）⇒ 「**前提有界时**」才无条件充分。
- **正文纪律**：「定理（解析严格界）」与「仿真（经验零漏）」必须分两句写，仿真不得反证定理。
