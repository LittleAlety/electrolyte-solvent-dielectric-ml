# W33-B：Kendall tau_b 的精确零分布与立项前预算工具

**性质**：统计工具化（P4）。不拟合模型、不占主记分牌 shot（累计仍 19）、不联网。

## 0. 一句话（全部由数据推出）

- **精确、不靠正态近似**：Kendall tau_b 与逆序数一一对应（`tau = 1 - 4K/(n(n-1))`），逆序数的 Mahonian 分布可精确枚举 ⇒ p 值与临界值用有理数精确算。
- **锚点 n = 7 上 0.90 是显著的**：`P(tau_null >= 0.90) = 0.001389`（判据门 0.01）⇒ 母体论文那条 n=7 的 0.9 阈值不是拍出来的，是精确算得出来的。
- **1/sqrt(n) 律在 n = 5..12 上成立**：`sd(n)·sqrt(n)` 的极差/中位 = 0.1806（门 0.25）⇒ R1 闭式的 1/sqrt(N) 形状在小 N 外推上也站得住。
- **口径不同不能混比**：精确零分布对应「无限总体、纯随机排列」，R1 闭式对应「有限总体 N_pop」；两者只在同一 N 上并排展示，不相互替换。

## 4. 判据（H33g–H33i）

- **H33g 成立**：1/sqrt(n) 律：精确零分布 sd(n)·sqrt(n) 在 n = 5..12 上的极差/中位（读数 0.180597 对阈值 0.250）。
- **H33h 成立**：锚点规模显著性：n = 7 时 tau >= 0.90 的精确单侧 p 值（读数 0.001389 对阈值 0.010）。
- **H33i 成立**：临界值单调性：alpha = 0.05 的精确临界 tau 随 n（5..12）单调不增（读数 -0.406061 对阈值 0.000）。

## 6. 口径与边界

- 精确零分布假设**无并列**（Kendall tau_a 口径）；有并列的真实读数按 tau_b 处理，此时精确表是**下界参考**，不得当作精确 p 值引用。
- 预算表的 s0 与 N_pop 取 W32-A 各通道中位，是**粗算**：正式预注册必须用该序列自己的 s0。
- 不改 METRIC_NAMES、不动冻结读数、不占 shot。
