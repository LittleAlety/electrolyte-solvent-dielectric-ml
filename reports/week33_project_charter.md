## W33-A：态合法性前置门禁 + 拒答队列 + 门禁后的排序重读

**门禁（预注册三条款，均在跑前写死）**：对每个（分子，介质）态：
1. `geom`：阴离子态 SCF/几何完好（`<medium>_anion_status == 'ok'`）；
2. `homo`：阴离子 HOMO < 0（等价于官方签名 `anion_unbound_<medium> == 'no'`，阈值 `UNBOUND_HOMO_SIGNATURE_EV = 0.0`）；
3. `ea`：绝热电子亲和 > 0（`ea_<medium>_eV > 0`）。

**合法集 = 三条款之交**；其余进**拒答队列**并记明理由（几何失败 / 阴离子不束缚 / EA 非正）。

**要回答的两个问题**：
- 单用 EA 条款会放进多少不束缚态？（GFN2 的 ΔSCF EA 在阴离子不束缚时是否仍为正 —— 这决定门禁条款能否只用一条）
- 门禁之后，还原轴的 τ_b 读数变成什么？在合法子集 **小于 5** 的层级上，预登记规则是**判为不可判定并拒答**，不得给出数值读数。这正是对 T2（Rathnakumaran 2026「单描述符失效」）的回答：不是描述符失效，是**描述符的定义域从未被声明**。

**判据（H33a–H33f）**：必要性（EA 单条款误纳率）、层级依赖（ORCA 层合法子集是否为空）、介质效应（通过率随 ε 非降）、读数改变（门禁前后 τ_b 的差）、跨层级裁决不一致率、拒答队列规模。

**复现锚**：全域 τ_b 必须逐位等于 `probes/artifacts/w24_3_level_crosscheck.csv` 的 `same_red_gfn2 = 0.8354978354978355` 与 `same_red_orca = −0.6017316017316018`（同一函数、同一对列），否则拒绝出报告。

## W33-B：Kendall τ_b 的精确零分布（P4）

R1 的闭式 `sd(N) = s0·sqrt(1/N − 1/N_pop)` 是**拟合**出来的；而小样本（n ≤ 10，尤其是 P2 提到的锚点 n = 7）的零分布可以**精确**算出来。做法：Kendall τ_b 与逆序数 K 一一对应（`τ = 1 − 4K/(n(n−1))`），逆序数的 Mahonian 分布由生成函数 `∏_{i=1..n}(1 + x + … + x^{i−1})` 精确给出。于是：

- 给出 α ∈ {0.05, 0.01, 0.001} 的**精确临界值**与精确 p 值（不依赖正态近似）；
- 把精确 sd 与 R1 闭式在 n = 7…12 上对照 —— 这同时是闭式在**小 N 外推**上的第一次独立检验（W32-A 的格点从 N = 10 起）；
- 输出一个可复用 CLI（`--n`、`--tau`、`--alpha`、`--target`），让 P1/P2 的预注册在**立项前**就能算噪声地板。

## 口径与边界

- 四张输入表逐位只读并记 sha256；**不重跑 xTB、不重跑 ORCA、不装依赖、不联网**。
