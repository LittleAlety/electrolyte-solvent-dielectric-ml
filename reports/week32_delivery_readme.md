# W32 交付说明：把抽样律推到四个通道，并补上第三个容量面

## 0. 一句话

W31 留下两个口子：抽样律**只在介电通道的层级口径上**被实测过，正则化两个旋钮**从未扫过中间值**。本轮一边把抽样律换成更严的「代理 vs 标签」并一次覆盖四个核心通道，一边在 W20-4 注册臂底座上补齐正则化曲线。

- **R1 成立**：有限总体修正闭式在全部 26 个序列上的拟合 rmse 中位 **0.007117**（门 0.012），最差一条 0.009927，100.0% 的序列 rmse ≤ 0.02。
- **R2 成立**：Spearman(s0, 1 − tau_b) = **0.806** —— s0 不是通道常数，而是**排序保真度的函数**；跨通道比噪声地板必须先把保真度对齐。
- **R5 成立**：dummy 均值臂的 tau_b 中位 -0.019394（门 |tau| ≤ 0.05），而其拟合 rmse 中位 0.007208 —— 闭式在**零信号**序列上同样成立，说明它描述的是「抽子集」这件事本身，不是被拟合出来的假象。
- **R4 登记**：冻结的介电层级口径 s0 带 [0.307, 0.542]，本轮「代理 vs 标签」的 s0 中位 0.446；两者**不同口径，不得直接混比**。
