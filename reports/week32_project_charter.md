# W32 立项章：把「排序不稳定性的抽样律」推到四个核心通道，并把正则化定成第三个容量面

- **本轮性质**：一条后验 lane（W32-A，不占 shot）+ 一条预注册主臂（W32-B，shot 19）。
- **上游**：W31-A（母体论文 v6 的三层对接）与 W31-B（容量交换阶梯，两条新预测判否）。
- **一句话**：W31-A 把 v6 的「样本规模」局限变成可复算的噪声地板，但它**只在介电通道的层级口径上被实测过**；W31-B 把容量拆成深度与叶惩罚两个面并证到二者正交，但**正则化这两个旋钮从未扫过中间值**。本轮一边把抽样律推到四个核心通道、一边补上第三个容量面。

## 0. 为什么是这两条

W31 收口时留下两个明确的口子，它们恰好对应「能不能把结论外推」与「还有没有没测过的旋钮」：

| 口子 | 现状 | 本轮的动作 |
| --- | --- | --- |
| 抽样律的适用范围 | 只在介电通道、且只在**层级 vs 层级**口径上实测（W24-3 的 6 条曲线） | W32-A：换成**代理 vs 标签**，一次覆盖四个核心通道（介电 / 黏度 / 轨道 / 氧化还原） |
| 正则化旋钮 | `colsample_bytree` 只读过冻结的 0.8 与放开的 1.0（两处都掉 0.039 ~ 0.048）；`subsample` 自冻结以来**从未动过** | W32-B：在 W20-4 注册臂底座上各扫一条曲线 |

第一条是**结论的外推检验**，第二条是**唯一没被扫过的容量面**——W29 与 W30 的结论「正则化在扛事」只说了方向，没说够不够。

## 1. W32-A：四通道 × 多代理（后验，零成本，不占 shot）

**对象换了**：W24-3 量的是「换一个电子结构层级之后排序位移的方向一致性」，本轮量的是「一个代理把标签排得对不对」。后者是筛选真正关心的量，也是更严的检验：前者的参照物与 参照系共享同一套分子池与同一批几何，后者的参照物是一个**会犯错的模型**。

**四个通道、26 个序列**（全部来自盘上已冻结的逐分子预测表，逐位只读、记录 sha256）：

| 通道 | 来源表 | 序列 | 评测单元 |
| --- | --- | --- | --- |
| 介电常数 ε | `dielectric_representation_ablation_predictions.csv` | 3（三种表示族） | 分子（对重复与折取均值） |
| 黏度 η | `viscosity_baseline_predictions.csv` | 3（三个模型，只取 group_key 划分） | **（分子 × 温度）行** |
| 分子轨道 | `l3_homo_lumo_cv_predictions.csv` | 8（4 个目标 × 2 个模型） | 分子（出折预测均值） |
| 氧化还原自由能 | `p4_redox_v2_predictions.csv` | 12（2 个目标 × 6 个模型，只取 cv_test） | 分子（对重复与折取均值） |

**方法**：每个序列在每个 N ∈ {10, 18, 25, 49, 100} 上无放回抽 1,000 个子集，算子集上的 Kendall τ_b，得到实测重抽曲线；再用单参数闭式 `sd(N) = s0·sqrt(1/N − 1/N_pop)` 拟合 s0 并报拟合残差。

**跑前写死的判据**：

| 判据 | 内容 | 门 |
| --- | --- | --- |
| R1 | 闭式在全部 26 个序列上成立（拟合 rmse 的中位） | ≤ 0.012 |
| R2 | s0 随排序保真度缺口上升：Spearman(s0, 1 − τ_b) | > 0 |
| R3 | 每通道给出最小信息预算（sd ≤ 0.05 所需 N） | 登记 |
| R4 | 与冻结的介电层级口径 s0 带（0.307–0.542）对比 | 登记 |
| R5 | 零假设对照：dummy 均值臂的 \|τ_b\| | ≤ 0.05 |

**为什么是可证伪的**：R1 允许闭式在这批「代理 vs 标签」序列上**失效**（拟合残差会说话）；R2 写成有方向的秩相关，若 s0 与保真度无关或反向，判否；R5 若 dummy 臂也能被闭式拟合得很好，说明这条律只是「抽子集」的算术，与排序信号无关——那同样要被登记。

## 2. W32-B：正则化中间值阶梯（预注册主臂，shot 19，约 25 分钟）

**要问的唯一一件事**：把注册臂当固定底座，正则化这两个旋钮到底是「缺」还是「多」？

**九个固定配置**（同一池、同一折、同一种子集，零选择器；前三档是复现锚）：

| 档位 | 与底座的差异 | 角色 |
| --- | --- | --- |
| `anch_frozen_d2` | 冻结档位（d2 / mcw1 / bin64） | 复现锚 `0.5861142332208197` |
| `anch_w20_4_registered_d4_mcw5` | —— | 复现锚 `0.6216672295270079` |
| `anch_w31_fixed_bin128_mcw7_d4` | mcw 7 | 复现锚 `0.6223892738254433` |
| `cs09_d4_mcw5_bin128` | `colsample_bytree` 0.9 | 新档位 |
| `cs10_d4_mcw5_bin128` | `colsample_bytree` 1.0 | 新档位 |
| `ss06_d4_mcw5_bin128` | `subsample` 0.6 | 新档位 |
| `ss07_d4_mcw5_bin128` | `subsample` 0.7 | 新档位 |
| `ss09_d4_mcw5_bin128` | `subsample` 0.9 | 新档位 |
| `ss10_d4_mcw5_bin128` | `subsample` 1.0 | 新档位 |

**判据 H32a–H32j**：四条复现锚（容差 1e-9 / 1e-6）、零跨界折、列采样单调下降、行采样存在中间最优点（> +0.002）、容量天花板未破（≤ 注册臂 + 0.005）、**序不变量用比值判据**、过门（≥ 0.60）。

**H32i 更正了 W31 的判据设计缺陷**：W31 的 H31h 拿 `R² 极差 > 0.08` 去卡一条按设计就窄的阶梯，结果量级侧必然不成立。本轮改成 `R2 极差 / AUC30 极差 > 1` 且 `AUC30 极差 < 0.02`——阈值随阶梯宽度自适应，方向与更宽阶梯可比。这条更正是 W31 报告里明确写下的「改法写进下一份预注册」，本轮照办。

**实现上不复制拟合代码**：直接复用 W31 已经过四条复现锚验证的 `evaluate_ladder`（只替换其模块级 `CONFIGS` 与 `ARM_PREFIX`）。四条复现锚因此同时是「代码路径未漂移」的证据。

**红线**：不改四个冻结读数、不改 `METRIC_NAMES`、不新增特征列、缺行不插补、不动 W28/W29/W30/W31 的任何产物。

## 3. 本轮不做

- **不**再往深度 / 树数 / 叶惩罚 / 分箱网格里加档位（W28–W31 已把这四个面逐一定价，容量天花板停在 W20-4）。
- **不**重跑已被证否的四条线（换拟合器、网络叠加、外来化学空间、杂类锚点）。
- **不**动 η 通道的行级解冻（已判否：0.1748 → 0.1570 对门 0.15）。
- **不**把 W32-A 的通道级噪声地板写进主记分牌：它是后验读数，不是新的评分口径。
