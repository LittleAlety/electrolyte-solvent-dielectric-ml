## 1. 本轮买到什么

W26 在 242 个化合物上把「电子结构对连续介质的**响应**」算了出来（14 档 ε 的 ddCOSMO 扫描、每化合物 Born 曲线、阴离子闸门、轨道能对 1/ε 的斜率）。W27 零新算力地把这 13 列响应量接在冻结主记分牌的稠密 lever4 块之后，问一个只有主记分牌能回答的问题：**把「响应量」当作第四个表示家族，Physical 表示动不动。**

答案是**净有害，而且干净**：五种子 Morgan+Physical 增量均值 **-0.096956**，5/5 种子同向（最差 -0.105477，最好 -0.085166），两条确认线（+0.02 / +0.005）双双判否。**本臂不晋升。**

## 2. 规模与覆盖

- 池：冻结主记分牌池 **2391 行**（2029 行基础 + 362 行外源），评分 **457 行 / 97 化合物**，训练池 full_base；`matches_preregistration = true`。
- 块：W26 的 **242 个化合物 × 13 列**，242/242 列全满（`w27_dielectric_response_block.csv`）。
- 覆盖：行级 **1768 / 2391 = 0.73944**；**评分化合物 97 / 97**（零缺口，因此这块不是被自己造出来的）。
- 运行：5 个冻结种子 × 2 个臂 + 1 个安慰剂，共 **11 次拟合**，单臂约 72 s，全轮**不跑 xTB、不装依赖、不联网**。
- 跨折泄漏：**10 个（种子, 臂）组合 × 50 折，含跨界化合物的折数全为 0。**

## 4. 三个最值钱的读数

1. **「响应量」这个表示家族在本配置下是净负的，而且不是种子运气。** 五种子增量 -0.101420 / -0.085166 / -0.105478 / -0.103637 / -0.089079，全部为负、离散度极小（极差 0.0203）。锚均值 0.541625、块均值 0.444670。至少在「稠密 lever4 + max_depth 2 / 200 树」这个配置里，13 列介电响应列携带的信息**打不过它带来的拟合负担**。
2. **安慰剂不惰性，这条比读数本身更值钱。** 把同一块的行顺序按冻结种子（2026）打乱后，增量仍有 **-0.006099**（超过 0.005 的惰性线）。也就是说：在只有 13–15 列的稠密块上再接 13 列，**哪怕这些列不含任何真实信息**，读数也会掉约 0.006。**因此「表示内容」的净效应是 -0.096956 - (-0.006099) = -0.090857**，剩下那 0.0061 是**容量/正则化效应**而不是信息效应。诚实地说，这条同时也是本轮的**一处自我削弱**：H27e 判否意味着这一枪的安慰剂没能通过它自己的干净线，任何引用本轮增量的人都必须把这 0.0061 单独定价。
3. **覆盖与复现零违规。** 97/97 评分化合物被块覆盖、1768/2391 行、10 臂 × 50 折零跨界、锚逐位复现（gap 恰好 0.0）。本轮的负结果是**在纪律全绿的前提下**取得的，不存在「因为块覆盖不全才掉分」的替代解释。

## 5. 判否的归因（必须并报）

- **H27c / H27d 判否 = 表示层的负结果，不是流程失败。** 池、评分掩码、切分器、拟合器、种子集全部逐字复用冻结主记分牌，块本身由盘上已有的 W26 产物派生（可逐行重算，见 `test_the_block_is_reproducible_from_the_frozen_w26_artefacts`）。唯一被改动的量就是表示块。
- **H27e 判否的机制解释（推断，不是实测）**：冻结的 XGB 超参（`max_depth = 2`、200 树、`lr = 0.05`）是当年为 **2048 维稀疏 Morgan 指纹**定的；在 13–15 列的稠密块上，每棵树只有 4 个叶，特征数从 13 涨到 26 会直接改变分裂预算与正则化强度。安慰剂掉的这 0.0061 正是这一效应的直接证据。**这条推断若成立，则 W27 与「给稠密物理配置重调超参」是同一族问题的两面**，下一步应对后者做一次预注册的 inner-fold 调参。
- **H27g 判否**：Physical 单表示的五种子增量 -0.085806（最小 -0.125034）与主读数同向，说明负结果不依赖 Morgan 块的存在。
- **不作为结论的三件事**：(a) 不能把本轮读作「介电响应量没有物理信息」——只能说在这套冻结配置下它不带来净增益；(b) 不能外推到别的名册或别的池；(c) 不能把 -0.096956 当作「信息量」，它是信息与容量效应的**混合**。

## 6. 口径纪律

- 层级：本仓 W27 的块来自 **GFN2-xTB / ddCOSMO 任意 ε / 刚性气相几何 / 242 分子**；母体论文 v6 = r2SCAN-3c / CPCM / 18 分子。跨层级只比函数形式与量级。
- **缺行不插补**：块在 W26 名册之外的池行上留 NaN，交给 XGBoost 自带的缺失值处理；不计算任何折内统计量，因此没有折内统计量可以泄漏。
- **块里没有任何一列触及被测的介电常数**：13 列全是溶质对**给定 ε 的连续介质**的响应，标签侧 ε 从未进入特征构造。
- 主读数口径与冻结锚一致（Morgan+Physical）；Physical 单表示只作描述性次读数并列报出，不单独构成晋升路径。
- 预注册修订 2 更正了锚的表示口径（修订 1 误标为 Physical），修订发生在只跑过 1 个种子的冒烟之后、五种子生产运行之前，**没有任何阈值被移动、列清单/臂/种子集/安慰剂规则均未移动**。
- 主记分牌 shot = 1（累计 13）；四个冻结读数（0.4091179943351143 / 0.4766400383507876 / 0.5861142332208197 / 0.6216672295270079）未动；三条输入红线逐条 sha256 复核。
