## 1. 本轮买到什么

W26 是本仓第一次用**任意相对介电常数**的连续介质（xTB 6.7.1 ddCOSMO，--cosmo EPSILON）做稠密介电扫描，也是第一次让**一条气相几何在全部 ε 与三个电荷态之间刚性共用**。W24-1 做过 Born 拟合，但它的扫描有两处结构性缺陷：用 --alpb 命名溶剂（ε 与溶剂身份不可分）且每个介质点都带 --opt（几何弛豫混进介电位移），而且只有 3 个非平凡 ε 点，ε ≥ 80.4 的一切读数都是外推。W26 逐条修掉。

## 2. 规模

- 分子池：242 个化合物（data/processed/w21_li_coordination_layer.csv 里气相特征齐全的全部行），242/242 几何成功。
- ε 网格 14 档：1（气相锚）, 2, 4, 7.58, 12, 18, 25, 35.688, 50, 80.4, 120, 200, 400, 1000。
- 扫描记录 10,164 行（242 × 3 电荷态 × 14 ε）；Born 曲线 726 条（242 × 3）。
- 模型层级对照 2,904 行：ALPB（thf 7.58 / benzaldehyde 18.0 / water 80.4）与 CPCM-X（acetonitrile 35.688）。
- 刚性 vs 弛豫对照：按 motif_class 分层抽 24 个分子，每个电荷态各取自己的气相最优几何，在 ε = 80.4 上复算。

## 4. 三个最值钱的读数

1. **介电层在 ε ≥ 200 上确实可以省，而且这次是实测不是外推。** 离子态 Born 前因子 |C| 中位 **2.5611 eV**，ε=200 的 Born 腔残余 12.81 meV，ε=200→1000 只再走 **10.52 meV** —— 与母体论文 v6 报的 10.81 meV 几乎同值。v6 的「ε ≥ 200 的加密点可以省」在本仓被独立复现。
2. **幂律口径也成立，但不该按字面读。** 残余乘 ε 的带内中位 **2.6111 eV**（v6 报 2.1 eV，同量级）。注意 v6 的「|ΔE|·ε ≈ 2.1 eV」里 ΔE 是**相对 Born 渐近线的残余**，不是总位移；按字面读总位移乘 ε 会得到随 ε 线性增长的量（本仓离子态 CV ≈ 1.3），那是口径误读、不是物理分歧。
3. **阴离子束缚闸门在 GFN2 层级不存在，原因在方法不在连续介质。** 242 个分子里 **154 个在气相就已经「束缚」**（气相 EA 中位 +1.92 eV，典型的半经验阴离子过度束缚），88 个气相未束缚的候选里只有 **10 个**在 ε ≤ 1000 内过闸。归因是干净的：气相 EA 的 p05–p95 跨距 **9.307 eV**，而整条介电扫描能提供的 EA 位移中位只有 **2.4684 eV**，比值 **0.2652** —— 连续介质不可能在这条轴上翻盘。这与本仓「还原轴必须靠 P2 / C1 承载」的既有结论同向。

## 5. 两条判否的归因（必须并报）

- **H1f 判否 = 冻结列语义，不是复现失败。** data/processed/w21_li_coordination_layer.csv 的 homo_free_eV / lumo_free_eV / total_energy_free_hartree 是 w21.parse_arm 读到的 xTB --opt 日志里的**首个 ISCF 块**（输入几何），不是优化后几何。把它按这个口径对，W26 复现偏差 **0.0 eV / 5.0e-11 Ha（484 个轨道对 + 242 个能量对，零违反）**，即通道逐位可复现（H1g 成立）。按原文口径（优化几何单点）则必然判否（最大 9.46 eV，且几乎全部来自含多片段的盐类分子）。本仓**不改**该冻结表，只登记这条口径。
- **H1e 判否 = W24-1 的 `--opt`-每介质做法并不无辜。** 几何弛豫对 ε=80.4 位移的贡献：中性对按构造为 0，阳离子对 **0.0132 eV**，阴离子对 **0.0967 eV**，离子对中位 **0.0547 eV**（阈值 0.05）。也就是说约 2.5 eV 的阴离子介电位移里，有约 4% 是几何弛豫而非介电响应。W24-1 的 2.1 eV 前因子因此被轻度污染，但结论方向未变。
- **H2b 成立但要打折看**：只有 10 个分子有闸门，且全部落在 ε = 2.0 这一格（网格最粗的一档），所以这个「中位 ≤ 40」几乎不含信息。H2a 才是 W26-2 的实质读数（判否）。

## 6. 口径纪律

- 层级必须同句声明：**本仓 W26 = GFN2-xTB / ddCOSMO 任意 ε / 刚性气相几何 / 242 分子**；**v6 = r2SCAN-3c / CPCM 裸扫描 / 18 分子 / 10 台阶**。跨层级只比函数形式与量级，绝不比绝对值。
- H1b / H1c / H1d 的主裁决取离子态（阳离子 + 阴离子），因为 v6 的 2.1 eV 与 19.6 meV 是氧化还原位移量；三态合并值并列报出（12.02 meV / 9.71 meV / 0.3787）。
- ddCOSMO / ALPB / CPCM-X 是三种不同的隐式溶剂近似；W26-3 只报差（ALPB 0.1355 eV、CPCM-X 0.0680 eV），不报谁更正确。
- 预注册修订 2 的操作化改写发生在**生产运行之前**（当时只跑过 8 分子冒烟），**没有任何阈值被移动**；修订依据写在 prereg.revision_note 与 smoke_pilot_evidence 里。
- W26-4（几何台阶 G1→G2）本轮未执行，只登记设计，不得被引用为已完成的几何台阶。
