# KPI 框架映射：Angew. Chem. Int. Ed. 2025, 64, e202416506

**论文**：Gao, Yuan, Huang, Yao, Yu, Chen, Zhang, Chen——*A Knowledge-Data Dual-Driven Framework for Predicting the Molecular Properties of Rechargeable Battery Electrolytes*，DOI `10.1002/anie.202416506`（本地副本 `C:/Users/Little Alety/Downloads/Angew Chem Int Ed - 2024 - Gao - ...pdf`，12 页）。

**它是什么**：KPI（Knowledge-based electrolyte Property prediction Integration），预测电解质分子的熔点/沸点/闪点（MP/BP/FP）的**知识–数据双驱动**框架。三个模块：① 数据组织与统计分析（API 抓取 → 隐式先验过滤 → 结构化表）；② 可解释性与知识发现（RDKit 64 维描述符 → SHAP → 可读规则）；③ 知识嵌入的分子性质预测（Uni-Mol 基座 + 知识向量）。

**它不是什么**：它不预测介电常数，也不处理"分子→集体极化"这类目标。它的三个目标（MP/BP/FP）是**相变温度**，受原子数与键型主导，可解释性和可达精度都远高于我们的 ε。

---

## 1 三条最直接可搬的东西（按可执行性排序）

### 1.1 知识纯度/流量控制器——它给出了我们杠杆 2 失败的一个候选解释

论文原话：**"As more features are embedded, the introduction of less relevant knowledge increases the learning burden to some extent, leading to a decrease in prediction accuracy."** 实测：把全部 64 维知识一次嵌入**不是**最优；按 SHAP 重要度排序后，MP/BP/FP 分别在**前 20/20/10 维**取到最好（R² 0.974/0.990/0.986），相对"不嵌知识"MAE 改善 6.7%/14.7%/17.8%。机制是**两个控制器**：纯度控制器（拼几维知识向量）+ 流量控制器（拼接比例可学习）。

**为什么打中我们**：本轮杠杆 2（6 个缔合特征一次性追加）实测 ΔR² = **−0.0119（死）**，杠杆 3（目标变换+稳健损失）**−0.1054（死）**。论文给的解释是"维度多≠好，无关知识增加学习负担"——也就是说**我们的失败可能不是"特征错"，而是"一次性全塞进去"**。它开的药方是**按重要度排序 + 纯度扫描（top-k）**，而不是整块进/整块出。

**但它的做法有泄漏风险，我们不能照抄**：论文的 SHAP 排序是在**全量数据集**上做的，再拿去训练。我们用必须**在每一折的训练侧内部**排序（per-fold），否则等于用测试集挑特征——这正是我们 X-4 明令禁止的"测试残差指导特征选择"。**我们要做得比它严。**

### 1.2 可解释规则 → 编码规则的"形状"，而不是原始计数

论文用 SHAP 得出的规则是**非单调、带饱和**的，例如：
- `#Donor` 重要度 18.7%；1/2/3 个给体相对 0 个给体，MP 平均 **+65.6 / +56.0 / +35.4 K**；**到 4 个给体就无明显变化**（氢键网络饱和）；
- 每多一个环 **+77.7 K**；每多一个双键 **+30 K**；`#Rot` 与 MP **负相关**（自由度↑ → 刚性↓ → MP↓）。

**为什么打中我们**：杠杆 2 加的是**线性计数**（donors、acceptors、密度）。论文显示这类信号的正确形状是**饱和型**。所以杠杆 2 死的第二个候选解释是**函数形状错配**，不是物理错。可执行的修法：把给体/受体系列编成**分箱哑变量 + 饱和项**（如 `has_1_donor / has_2 / has_3plus`），而不是一个连续计数。

### 1.3 知识嵌入进 3D 基座模型时"要带控制器"

论文用的是 **Uni-Mol** 基座 + 知识向量（纯度/流量控制器）微调；消融显示去掉原子/键/整分子任一知识组件都会掉点。这正是我们附录 X 的**杠杆 6（Uni-Mol 3D 微调）**，而论文告诉了我们**怎么接**：不要裸微调，要把物理/知识向量以**可调纯度**拼进表示。

## 2 三条次要但有用的东西

### 2.1 适用域的第二族规则：结构白名单
KPI 的数据侧硬闸门是**分子量 0–600、重原子数 0–30、元素白名单 {H,C,N,O,F,Si,P,S,Cl,Br,I}**；高通量筛选中还**先剔除含活泼氢（–OH、–COOH）的分子**再进入预测。这是与我们（SMARTS 缔合规则）和包络闸门（特征区间/kNN）**不同族**的第三条适用域规则，且来自第三方。注意它剔–OH 的动机与我们相反：它是为了**电化学活性**，我们是因为**缔合盲区**——同一类基团在两个口径下都被判"不能直接用"，值得并排写进漏斗规范。

### 2.2 多性质相关性 → 辅助任务
论文实测 MP–BP ρ=0.81、BP–FP ρ=0.97，并据此论证"相变性质共享分子间作用力驱动"。对我们是"ε 与黏度/折射率/密度共享分子间作用力"——我们**两条线都有**（介电线 + 黏度线）。多任务/辅助目标是一个真实可选项，但在 97 化合物评分池上风险高，只能作探针。

### 2.3 它自己的失败模式，是我们的天花板诊断的第三方旁证
论文结论段原话：**"the current molecular descriptors can not adequately describe solid–liquid transition... as prior knowledge is necessary to improve the prediction accuracy of MPs"**——当目标被**分子间/集体效应**主导时，单分子描述符结构性不足，必须补先验知识。这正是我们附录 X-2 的"缺 Kirkwood g 维"结论的**独立复述**，而且出自一篇拿到 18/20 SOTA 的论文。

### 2.4 数据规模对照（诚实记账）
KPI 的 MP/BP/FP 数据集 = **4,235 / 4,153 / 3,504** 个分子；我们 = **246 名册 / 97 化合物评分池**。但两边的可学性不同：它的目标是原子数主导的相变温度（R² 0.97–0.99），我们的目标是集体极化（R² 0.409）。**规模差是事实，但它不是我们低 R² 的主因——目标的信息结构才是。**这句话两边都要写清楚，不许拿"人家数据多"当借口，也不许拿"我们的问题更难"当挡箭牌。
