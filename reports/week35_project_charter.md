## W35-A：门禁旁路层与下游消费者审计

**问题**：W34-A 的注册表是权威列，但它是**按（层级 × 介质 × 分子）**组织的长表（1028 行）。任何**按分子**引用还原轴的下游（例如「这个化合物在气相层可不可宣读」）都要自己去 join；更关键的是，**没有任何检查**会告诉维护者「你引用的那个数在当前门禁下不可宣读」。

**要交付的三个件**：

1. **旁路表**（`data/processed/redox_readability_sidecar.csv`）：按 InChIKey 一行一键（**246 行**），把 W34 注册表里 GFN2 四介质与 ORCA 两介质的 `legal` / `reason` 摊平成列，另给 `in_paired_orca`（该键是否在 R6 的 22 个配对化合物里）、`n_gfn2_legal_media`、`readable_gfn2`、`n_orca_legal_media`、`readable_orca`。**这是派生旁路，不修改主注册表**（主注册表 sha256 必须逐位不变）。
2. **引用登记表**（`probes/artifacts/w35_gated_reference_register.csv`）：把仓库里**所有**引用还原轴数值的点登记成行，每行**调用 W34-A 的守卫**得出 `mark`，拒答就写成「不可判定」。共 **10 行** = R6 的四条 `tau_b`（`w24_3_level_crosscheck.csv`）+ W33-A 的六个门禁后读数（`w33_bound_state_gate_gates.csv`）。**门禁范围声明**：本门禁是**阴离子态**审计，只覆盖**还原轴**；氧化轴两条登记为「不适用（门禁只覆盖还原轴）」——这是本轮新增的一条口径，防止把阴离子门禁误用到阳离子轴。
3. **消费者审计**（`probes/artifacts/w35_gated_consumer_audit.csv`）：登记**七个**下游消费者（论文 §3.20 / §3.21 / 附录 A / 结论 #8、W34 看板、决策日志 §28.87 / §28.88），逐段检查「若该段引用了受门禁约束的数值（`0.602` / `0.835` / `1.437`），则同一段必须出现标记 `不可判定`」。审计在更正前应**至少报出两处缺失**（§3.20、附录 A），更正后全部成立——审计的价值就在于它**先失败、后被修好**。

## W35-B：R6 口径更正（预注册驱动）

**问题**：论文写「**氧化轴对层级不敏感**：换层级只动 0.043」。W34-B 的配对 bootstrap 给出该 Δτ 的 95% 区间 **[−0.1982, +0.0909]**，**跨 0**。因此正确表述是「**在 n = 22 上未检出差异（不可分辨）**」，而不是「不敏感 / 无差异」。

**做法**：把四条替换写成预注册件 `probes/w35_paper_r6_correction_prereg.json`（`status = locked_before_run`），再由 `probes/w35_paper_r6_correction.py` **按预注册逐条施加**（幂等：已施加则只校验）。四条的定位规则与替换文本全部写死在预注册里：

| id | 定位 | 更正 |
| --- | --- | --- |
| C1 | §3.20 第 1 条要点 | 「氧化轴对层级不敏感」→「氧化轴未检出差异（不是「无差异」）」并带上 95% 区间与「跨 0 ⇒ n = 22 不可分辨」；原「与 R2 的 \|σ\| ≤ 0.04 在同一量级」降级为旁证 |
| C2 | §3.20 的「限制照实登记」段 | 追加一句**分辨率与定义域必须并报**：氧化轴区间跨 0、还原轴区间不跨 0，但还原轴两层读数在 W33-A 门禁下均判**不可判定** |
| C3 | 附录 A「跨层级对照（22 化合物）」行 | 补区间与门禁判词（原 0.835 / −0.602 / −0.043 三个数字**原位保留**） |
| C4 | 结论 #8 | 同一句内补「（95% 区间跨 0 ⇒ 未检出差异）」与「该轴门禁判不可判定」 |

**不改什么（预注册写死的不变量）**：所有既有数字（0.697 / 0.654 / +0.835 / −0.602 / −0.043 / −1.437 / −0.467 / 246 / 22）**原位保留**，只加注记；不改判词方向（还原轴仍记为「翻号可分辨」）；不改摘要（主结果二只陈述「只动 −0.043」这个事实，未断言「不敏感」）；不改任何冻结读数。

## 口径与边界

- 输入表逐位只读并记 sha256；**不重跑 xTB、不重跑 ORCA、不装依赖、不联网**；全轮零新算力。
- **拒答不是缺失值**：登记表里 ORCA 两层的 `mark` 就是 W34-A 守卫抛出的拒答结论，不得插补、不得赋伪值、不得静默丢弃。
- **门禁范围**：本门禁是**阴离子态**审计（geom ∧ homo ∧ ea），只对**还原轴**生效；氧化轴登记为「不适用」，不得把阴离子门禁套到阳离子轴上。
- **区间跨 0 = 未检出差异，不等于证明无差异**。
- W35-B 是**预注册驱动的改稿**：改动来自锁定件、可复算、幂等；报告记录改前 / 改后的论文 sha256。
- 不改 `METRIC_NAMES`、不新增特征列、不动四个冻结读数与 ε 主记分牌；两个 lane 均不占 shot。
