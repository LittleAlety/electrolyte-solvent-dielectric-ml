## 2. W33-A：态合法性前置门禁

**门禁 = 三条款之交**（预注册写死，`probes/w33_bound_state_gate_prereg.json`，`status = locked_before_run`）：

- `geom`：阴离子态 SCF/几何完好（`<medium>_anion_status == 'ok'`）
- `homo`：阴离子 HOMO < 0（等价于 `anion_unbound_<medium> == 'no'`，阈值 0.0）
- `ea`：绝热电子亲和 > 0（`ea_<medium>_eV > 0`）
- **合法子集 < 5 判「不可判定」**（拒答），不得插补、不得赋伪值、不得静默丢弃。

### 2.3 判据（H33a–H33f）与复现锚（A1–A3）

- **H33a 成立**（0.398374 ≥ 0.30）、**H33b 成立**（ORCA 气相合法子集 0 < 5）、**H33c 成立**（通过率随 eps 非降）、**H33d 成立**（门禁前后 tau_b 最大差 0.182004 ≥ 0.10）、**H33f 成立**（气相拒答率 0.788618 ≥ 0.70）。
- **H33e 判否**：预注册猜「两层裁决不一致占多数」，实测两层在这 22 个锚点上**高度一致（一致率 95.5%）**；层级依赖体现为「合法子集不够读数」，而不是「裁决互相矛盾」。**判否照实登记，不改写**。
- **A1/A2/A3 逐位命中**：GFN2 配对集 +0.8354978354978355、ORCA 配对集 -0.6017316017316018、气相不束缚占比 0.7642276422764228；任一锚不中，脚本**拒绝出报告**。

## 3. W33-B：tau_b 的精确零分布与立项前预算

Kendall tau_b（无并列）与逆序数 K 一一对应（`tau = 1 - 4K/(n(n-1))`），逆序数的 Mahonian 分布由生成函数 `prod_{i=1..n}(1 + x + ... + x^{i-1})` **精确枚举**，p 值与临界值用 `Fraction` 有理数精确算，不依赖正态近似。

### 3.1 精确零分布表

| n | 精确 sd | sd·sqrt(n) | 临界 tau(0.05) | 临界 tau(0.01) | 临界 tau(0.001) |
| --- | --- | --- | --- | --- | --- |
| 5 | 0.408250 | 0.912871 | 0.8000 | 1.0000 | nan |
| 6 | 0.354860 | 0.869230 | 0.7333 | 0.8667 | nan |
| 7 | 0.317062 | 0.838872 | 0.6190 | 0.8095 | 1.0000 |
| 8 | 0.288675 | 0.816497 | 0.5714 | 0.7143 | 0.8571 |
| 9 | 0.266445 | 0.799335 | 0.5000 | 0.6667 | 0.8333 |
| 10 | 0.248452 | 0.785674 | 0.4667 | 0.6000 | 0.7778 |
| 11 | 0.233550 | 0.774596 | 0.4182 | 0.5636 | 0.7091 |
| 12 | 0.220959 | 0.765410 | 0.3939 | 0.5455 | 0.6667 |

- **H33g 成立**：`sd(n)·sqrt(n)` 在 n = 5..12 上的极差/中位 **0.180597**（门 0.25）⇒ 1/sqrt(n) 形状在小 N 外推上也站得住。
- **H33h 成立**：锚点 **n = 7 时 `P(tau_null ≥ 0.90) = 1/720 = 0.001389`**（门 0.01）⇒ 母体论文那条 n=7 的 0.9 阈值**不是拍出来的**，是精确算得出来的。
- **H33i 成立**：α = 0.05 的精确临界 tau 随 n 单调不增（0.800 → 0.394）。
- 已修一处**真 bug**：`critical_tau` 初稿取错成**负尾**（n=5 返回 -0.8），已改为「累积概率仍 ≤ α 的最大 K」⇒ 正值；`tests/test_w33_kendall_null_tool.py` 用 `critical_tau(5,0.05) == 0.8` 等逐值回归钉死，防复发。

## 4. 口径与边界

- 两 lane 都**不占 shot（累计仍 19）**、不改 `METRIC_NAMES`、不新增特征列、缺行不插补、不动四个冻结读数。
- **拒答不是缺失值**：拒答 = 「在本层不可宣读」的明确结论；ORCA 两层均 < 5 合法子集，报告必须写「不可判定」，**不得引用 -0.602 作为该层读数**。
- 跨层级只在配对集上比裁决一致性，**不把两层数值结果混在同一张记分牌上**。
- W33-B 的精确零分布假设**无并列**（Kendall tau_a 口径）；有并列的真实读数按 tau_b 处理，此时精确表是**下界参考**，不得当作精确 p 值引用。
- 预算表的 s0 与 N_pop 取 W32-A 各通道**中位**，是粗算；正式预注册必须用该序列自己的 s0。
- W33-A / W33-B 按附录 C 属后验读数 / 工具，**不得当作预注册结论引用**；单表示读数永不与冻结头条 `0.4766400383507876` 混比。
