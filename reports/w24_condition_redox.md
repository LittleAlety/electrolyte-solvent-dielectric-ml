## 5. 如实登记的限制

- 层级：GFN2-xTB 半经验 --opt，不是 DFT 级；论文的 C 台阶是 r2SCAN-3c，本臂是低层级实例化，绝对值不可直接比
- 绝热口径（三态各自优化）与垂直口径不同，不得与本仓历史垂直数值或论文的垂直三点法混比
- C_2 只用了一个确定性的反式 2:1 起始构型，不是最低能异构体，也不是 population 平均；框架 3.2 明令禁止把不同化学计量 cluster 混做 Boltzmann 平均，本臂遵守
- C_1 的 ref 态锚到 W21 是必要的资格检查；阳极（+2）态在气相可能发生库仑解离，QC 如实登记，不以失败臂推断化学
- 本臂不引用任何 Reaxys 数值；Batt-P30K / RX-392 只在别处作参考层，本臂不涉及
- 氧化轴方向约定：S_ox 越大越难氧化 = IP 与 -eps_HOMO；还原轴 S_red 越大越难还原 = -EA 与 eps_LUMO
