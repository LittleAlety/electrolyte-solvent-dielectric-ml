### W25-2 · f_robust_inv 的「矛盾」归因

- 本仓同名量在 **38 / 38** 个台阶-轴上非零（最大 **0.3931**，均值 0.1078），v6 报 40 个读数全 0。
- **同源**：rho(f_robust, f_unresolved) = **0.9361**，CI [0.856, 0.967] —— 本仓的 f_robust 是 f_unresolved 的单调再表述，不是新量。
- **预注册 H2 判否**：38 个非零里 **10 个**不满足「C 台阶 或 f_unresolved >= 0.30」的门（违反者中最小 f_unresolved 低至 **0.262**），
  所以「非零来自条件态台阶」这个机制假设**不成立**；违反者名单逐条落盘（`week25_summary.json` 的 `robust.prereg_h2_violator_rungs`）。
- **真正的解释是同名不同阈**：本仓 `f_robust_inversion` 用**绝对 0.05 eV** 分辨（源侧位移差与对间差都 >= 0.05 eV 才算已分辨），
  v6 的 `frobustinv(z)` 用**随 σ 缩放**的阈（已分辨等价于 gap >= z·σij，σij = |δi - δj| / sqrt(2)）。
  在后者口径下，位移离散度大的台阶几乎整轴自动落入 unresolved，「已分辨却仍然翻转」的窗口**按构造为空**，
  那 40 个 0 因此是**阈值约定的产物**；本仓的绝对阈让同一窗口处处非空。v6 自己给出的敏感性
  （改用 σij² = (δi² + δj²)/2 时 unresolved 升到 0.95-1.00）与这条同向。
- H2a **成立**、H2b **判否**（最大 0.3931 > 0.20）。

### W25-7 · 直接学习 vs 位移学习（后验臂，**未预注册**）

v6 的方向 9 在本仓此前没有对照。本臂用同一个 KRR 代理（RBF，alpha 由训练折 LOO 选择）在 **237** 个化合物上比较两种形状：
direct 直接学配位层能级；shift 学位移 delta 再把自由层回加。关键在**两套特征集**：

| 特征集 | 内容 | 性质 |
| --- | --- | --- |
| `x0` | 5 项廉价列（含自由层能级本身） | **退化控制组**：shift 目标 = direct 目标 − 自由层，而自由层就在特征里，两者近乎同一份信息 |
| `off_free` | 去掉三列轨道量，只剩 `formal_charge` + `total_energy_free_hartree` | **实质比较**：自由层只能经目标代数注入 |

| 轴 | 特征集 | direct tau_b | shift tau_b | delta tau_b | 95% CI | 正向重复 | delta R2 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| ox | x0（控制） | 0.5946 | 0.5949 | +0.0003 | [-0.003, 0.003] | 5/10 | +0.0244 |
| ox | **off_free** | 0.2675 | 0.5553 | **+0.2878** | [0.281, 0.294] | **10/10** | **+0.6241** |
| red | x0（控制） | 0.3819 | 0.3944 | +0.0125 | [0.004, 0.020] | 8/10 | +0.0481 |
| red | **off_free** | 0.0896 | 0.1978 | **+0.1082** | [0.095, 0.122] | **10/10** | **-4.6531** |

- **控制组是空的、实质组是满的**：x0 那对的 delta 只有 0.0003 / 0.0125（区间宽度 < 0.03），off_free 那对两个轴都是 10/10 正向且区间不含 0。
  这说明「位移学习更好」在**本仓特征集下不是普适规律**，而是**取决于自由层能否从特征读出**。
- **留一家族出（LOFO）更硬、也更分轴**：ox / off_free 的均值 **+0.4703**，4 个有效家族**全部正向**；red / off_free 均值 +0.3720，但只有 **2/4** 正向（alkene_pi +0.807、aromatic_pi +0.800 为正，lone_pair -0.066、no_motif -0.053 为负）。
  anion_halide 只有 2 个化合物、tau_b 在 n < 3 时未定义，从均值与计数里剔除（families_total 仍记 5）。
- **赢的那一半带着代价**：red / off_free 的排序 delta 是 +0.1082，但**原尺度 R2 反而掉到 -4.65**。这正是本仓反复出现的那条：
  **排序学会了、量级学不会**；引用这条读数时必须把两个数一起写，不能只报 tau_b。
- 与 v6 的关系：v6 唯一为负的分组是「C0→C1 还原轴」，本仓的还原轴也是**唯一在原尺度上崩掉**的那条 —— 方向同向，量级不同。


## 2. 跑中修正登记（四处，判据一条未改）

1. **首跑卡死：BLAS 线程超订**。首跑在 W25-1 / W25-2 落盘后（12 s 内）进入主动学习重放，之后 **20 分钟以上无任何进展**
   （进程 CPU 持续增长、零输出）。单测显示单次 120 步重放本应约 0.6 s —— numpy 2.5 在本机为每个核起一个 BLAS worker，
   n <= 246 的微型解方程全部耗在线程屏障上。修法：**在探针顶部把 OMP / OpenBLAS / MKL / NUMEXPR / VECLIB 五组线程数锁为 1**
   （运行期设定，不改预注册、不改任何统计口径），并加阶段进度输出。重跑 **43 s 完成**。
   **证据**：首跑与后续每一次重跑产出的 W25-1 / W25-2 两份 CSV **逐字节相同**（`131276c5…` / `37f5058b…`），
   说明该修正没有移动任何读数。
2. **预注册 H2 未被评估**。冻结预注册里 W25-2 的判据是「每个非零翻转必须落在 C 台阶或 f_unresolved >= 0.30」，
   而探针首版只算了 H2a / H2b（相关系数与最大值）—— **仪器偏离**。修法：按 locked 口径补算 H2 并单列裁决（**判否**，28/38 过门），
   H2a / H2b 作为同轮的探索性细化保留并明确标注。
3. **池规模标注错误**。图 C 标题、报告 §3 标题与图注原写「池 = 246」，实际入池 **237** 行。已改为从
   `al_summary["n_pool"]` 读取，并在报告 §3 明写「246 名册里特征齐全的 237 行，不齐的行在入池前剔除，标签未删」。
4. **W25-7 的 LOFO 计分口径缺陷**（该臂内部发现，错误版本从未提交或导出）。首版 `cross_validate` 用 `np.empty` 建预测向量、
   并对**整条向量**计分；留一家族出模式下只有留出家族那几十行被填过，其余是未初始化内存，等于把未定义项混进 tau_b / R²。
   修法：指标只在**被预测到的行**上读（random 模式覆盖全池，取值不变；LOFO 每个读数都变），并把化合物数 < 3 的家族
   （anion_halide，2 个）的 tau_b 记为未定义、从均值与正向计数中剔除。
   **证据**：修正前后 random 模式的四个 delta 完全一致（0.00028607 / 0.01248670 / 0.28782149 / 0.10816803），
   只有 LOFO 数字移动（例如 ox / off_free 的 LOFO 均值由 +0.0652 变为 +0.4703）。
