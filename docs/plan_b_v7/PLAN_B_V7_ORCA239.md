## 1. 本轮修订要解决的问题

v6.0 的 DFT 层使用 PySCF/B3LYP/def2-SVP，而原计划要求 ORCA/r²SCAN-3c。这属于**方法替换**，不是等价实现，因此 v6.0 的 DFT 结论不能自称满足原方法学要求。

v7.0 的修订目标是：

1. 用真正的 ORCA 6.1.1 + r²SCAN-3c 重建统一 DFT 层；
2. 把"电子结构方法差异"和"几何优化差异"分开度量，而不是混在同一个比较里；
3. 在统一方法下重跑 E1/E2/E3/E4/E6，看 v6.0 的结论是否成立；
4. 完整保留 v6.0 的 235 个 B3LYP 结果作为独立历史方法层。

## 3. 方法学定义（冻结）

```
程序      ORCA 6.1.1
方法      r²SCAN-3c  (r²SCAN + D4 + gCP + def2-mTZVPP, ORCA 内置)
电荷/多重度 0 / 1
SCF       MaxIter 300, TolX 1e-7, TolE 1e-8
响应性质  %elprop Polar 1  → 静态极化率（响应理论）
并行      4 MPI ranks, maxcore 2000 MB
```

**方法标签的边界**：`r²SCAN-3c` 是为几何与热化学参数化的复合方法。预检只证明了
"偶极与极化率能被正确解析，且与独立 ORCA 运行一致"，**不**证明 D4/gCP 修正已完整
进入响应性质的导数计算。报告中不得把能量方法标签等同于响应性质的完整方法定义。

## 4. 计算分层（三层）

| 层 | 几何来源 | 电子结构 | 目的 |
|---|---|---|---|
| L1 固定几何 | GFN2-xTB 优化 | r²SCAN-3c 单点 | 分离**方法效应**：只有方法变 |
| L2 优化几何 | r²SCAN-3c 优化 | r²SCAN-3c | 生产特征层：几何与性质内部一致 |
| L3 历史对照 | GFN2-xTB 优化 | B3LYP/def2-SVP（v6.0） | 历史方法层，不覆盖 |

派生量：

```
geometry effect = L2 - L1        （同方法，几何变）
method effect   = L1 - xTB(L1几何)（同几何，方法变）
total effect    = L2 - xTB
```

## 6. 自主调整边界

允许（记录在案，不改变科学定义）：

- CPU 线程数、单任务内存、Walltime、队列、批次大小、并发数；
- 临时目录、调度方式、解析器修正、失败重试策略；
- 不改变方法定义的数值收敛参数（SCF 迭代上限等）。

禁止：

1. 把 r²SCAN-3c 换成 B3LYP 或其它泛函；
2. 混用不同基组/复合方法到同一计算层；
3. 改分子身份、电荷、多重度；
4. 改 ε 目标定义或 ACCEPT 标准；
5. 为改善结果修改测试集或 Top-k/regret 规则；
6. 覆盖 v6.0 数据。

## 8. 尚未关闭的问题

1. **来源独立性**：239 分子仍以单一编校来源为主，独立印证分子少；所有"239"只表示计算覆盖。
2. **LOFO 失效区已分解**：7/11 家族差于族内常数基线，但机制不同——
   - 水平标定：halocarbon（bias 占 MAE 93.8%，去偏后 1.69 < 基线 1.95）、other_neutral_liquid（88%）；
   - 单点外推：nitrile（HCN ε=114.9 一个点占 MAE 65%，去掉后 19.77 → 6.99）、ester（Triolein 900 Da，预测 −56.3）；
   - 真实排序失效：仅 ether（ρ = −0.135，"醚"标签下氯代醚与脂肪醚化学异质）、nitro（ρ = 0.28）。
   6/11 家族族内 ρ ≥ 0.69，说明描述符携带的排序信息在多数家族内可迁移。
   证据见 `outputs/b700/B706_E4_family_diagnostics.json`。
3. **构象信息无预测增量**：227 构象已完成，Boltzmann 平均改变 22.8% 偶极数值但不改善与 ε 的相关。
4. **xTB on DFT 几何**（2×2 完整矩阵缺的一格）：可补，但 §4.2 已显示几何效应极小，优先级低。
5. **液体相构象分布**：当前用气相电子能量权重，不是液体中的真实分布，也不是 Gibbs 自由能。

以上 1–3 是论文必须正面讨论的限制；4–5 是可选扩展。
