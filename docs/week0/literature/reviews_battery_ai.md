## 1. Gao 等：Accelerating battery innovation: AI-powered molecular discovery

### 1.1 书目与 DOI

- 作者：Yu-Chen Gao, Xiang Chen, Yu-Hang Yuan, Yao-Peng Chen, Yi-Lin Niu, Nan Yao, Yan-Bin Gao, Wei-Lin Li, Qiang Zhang。
- 题名：*Accelerating battery innovation: AI-powered molecular discovery*。
- 期刊：*Chemical Society Reviews*, 2025, 54, 9630-9684。
- DOI：`10.1039/d5cs00053j`；Received 5 May 2025；Published 22 September 2025（PDF p.2 / 印刷 p.9630）。
- 卷期信息：Volume 54, Number 21, 7 November 2025, issue pages 9577-10308（PDF p.1）。

### 1.2 研究范围

这是一篇面向电池分子的“表示-算法-性质预测-分子设计”全景综述。范围覆盖电解质、电极和其他辅助材料，但问题核心是电池功能分子的发现，而不是单一声学或电化学器件（PDF pp.4-6 / 印刷 pp.9632-9634）。作者把流程分成五段：分子表示、AI 模型、关键物性预测、分子设计和闭环实验；应用层面覆盖解释性 ML、HTVS、生成式反向设计和 HTE/自主实验室（PDF p.6 / 印刷 p.9634）。

### 1.4 关键结论

- AI 的价值不只在加速拟合，而在于把分子表示、结构-性质关系和实验反馈连成可迭代发现流程（PDF pp.2, 14 / 印刷 pp.9630, 9642）。
- 小数据通常更适合低维、化学可解释的描述符和经典模型；大数据和复杂结构任务更能体现表示学习、GNN/Transformer 等优势。文中举例：从 199 个描述符中选出 37 个后，六个模型的分类准确率由 46.8%-79.1% 提高到 71.0%-83.7%（PDF p.7 / 印刷 p.9635）。
- 介电常数已经被单列为 AI 可预测的关键电解质物性。文中报告 QSPR 的 \(R^2=0.956\)；497 个化合物的 ANN 测试 RMSE 为 2.33，专门子特征模型降至 1.85；EC/DMC/LiFSI 混合体系 ANN 经 20,000 个训练步后 MSE 约为 0.0088（PDF p.27 / 印刷 p.9655）。
- 介电常数不足以单独描述锂盐溶解和解离，作者进一步引入 DN/AN 等溶剂电子给予能力指标；CatBoost 对 DN、AN 的测试 \(R^2\) 分别为 0.86 和 0.96（PDF pp.27-28 / 印刷 pp.9655-9656）。
- 生成、筛选和实验闭环均已有代表性成功案例，但作者仍把数据基础设施、小样本/迁移学习、跨尺度模型和算力列为四个核心前沿（PDF p.40 / 印刷 p.9668）。

### 1.5 局限

- 现有数据库碎片化、实验协议不一致、元数据缺失，且对固态聚合物和多元离子等新兴体系的覆盖有限（PDF p.40 / 印刷 p.9668）。
- 小样本仍是电池领域的常态，零样本/少样本、迁移学习和跨尺度建模尚未形成通用方案（PDF p.40 / 印刷 p.9668）。
- 高维深度模型通常牺牲可解释性；可解释模型又可能受线性或分段线性假设限制，难以完整表达复杂界面过程（PDF p.31 / 印刷 p.9659）。
- 主动学习与自动实验需要高质量、可重复的反馈，而文中同时指出数据生成和治理成本很高；算力增长还带来能源消耗问题（PDF pp.38-40 / 印刷 pp.9666-9668）。

### 1.6 与本项目“电解液溶剂介电常数 + 主动学习”的直接关系

- 原文直接把介电常数定义为调节离子-溶剂、离子-离子相互作用和溶剂化结构的关键参数，这为项目的目标变量提供了物理依据（PDF p.27 / 印刷 p.9655）。
- 原文的混合体系 ANN 案例说明，介电常数不仅是纯溶剂性质，还随 EC 比例和盐浓度变化，因此数据模型必须显式记录组分比例、盐种类/浓度和温度，而不能仅用单分子描述符（PDF p.27 / 印刷 p.9655）。
- GPR 小节明确给出均值与预测方差，可自然提供不确定性；这正适合作为主动学习中的采集函数基础（PDF p.19 / 印刷 p.9647）。
- 原文建议主动学习选择“高信息价值”样本并平衡探索/利用，同时用 BO/采集函数规划后续实验（PDF p.38 / 印刷 p.9666）。项目可把该闭环从“仅优化电导率或溶解度”迁移到“介电常数 + 黏度/电导率/稳定性”的多目标问题。
- 直接空白：原文没有展示“介电常数预测 + 主动学习 acquisition”真正闭环的完整案例。现有介电案例多为离线拟合；主动学习案例主要优化配方性能，而非直接优化介电常数。

### 1.7 可复用到 Week 1 的行动项

1. 建立最小数据字典：SMILES/InChI、溶剂类别、盐类型、浓度、摩尔比、温度、频率、测量方法、介电常数及其不确定度；所有混合体系另记组分分数。
2. 将数据分成纯溶剂、二元溶剂、含盐体系三类，分别设计随机划分与分子骨架/体系外推划分；不可只报告随机 CV。
3. 先跑可解释的中小样本基线：岭回归、RF/GBR、GPR；数据量显著增加后再增加 ANN/GNN。
4. 为 GPR 定义不确定性与校准指标，并比较均值预测、方差预测和留一/分组验证；采集函数先在已有数据上做离线 replay，不直接做昂贵实验。
5. 设计一个主动学习模拟器：初始化多样性采样，比较随机、贪心预测最优、EI/UCB 或“预测值 + 不确定性”的组合策略，以固定实验预算下的命中率和误差下降评估。
6. 把介电常数与 DN、偶极矩、极化率、盐解离/离子电导率联动，避免单指标过拟合；至少在报告中明确介电常数不是锂盐解离的唯一判据。
7. 从 Week 1 就采用 FAIR 元数据和版本控制；记录缺失值、测量条件与异常原因，而不是静默删除。

### 1.8 页码核验点

- PDF p.7 / 印刷 p.9635：37 个描述符、199 个初始描述符及分类准确率区间。
- PDF p.19 / 印刷 p.9647：GPR 同时给出预测均值和预测分布/方差，可用于不确定性。
- PDF p.27 / 印刷 p.9655：QSPR \(R^2=0.956\)、ANN 测试 RMSE 2.33 与 1.85、混合体系 MSE 约 0.0088。
- PDF p.40 / 印刷 p.9668：数据碎片化、元数据缺失、小样本/迁移学习与 FAIR 数据治理。

## 2. Zhan 等：AI for battery-accelerated discovery of high-voltage electrolytes for advanced lithium batteries

### 2.1 书目与 DOI

- 作者：Yu Zhan, Nan Chen, Li Li, Feng Wu, Renjie Chen。
- 题名：*AI for battery-accelerated discovery of high-voltage electrolytes for advanced lithium batteries*。
- 期刊：*Chemical Society Reviews*, 2026, 55, 6625-6674。
- DOI：`10.1039/d4cs01250j`；Received 2 December 2025；Published 3 June 2026（PDF p.2 / 印刷 p.6625）。
- 卷期信息：Volume 55, Number 12, 22 June 2026, issue pages 6455-6928（PDF p.1）。

### 2.2 研究范围

本文聚焦高压锂电池电解质，并提出 AI for Batteries（AI4B）范式：用数据学习与物理约束连接分子描述符、溶剂化结构、界面反应和宏观性能（PDF pp.2-3 / 印刷 pp.6625-6626）。正文覆盖 ML/AI 方法、液相和固相电解质高通量筛选、智能表征、多尺度建模、MLMD、高电压失效分析、结构解析、氟化/无氟电解质和功能添加剂（PDF pp.11-37 / 印刷 pp.6634-6660）。

### 2.4 关键结论

- 液相电解质筛选主要有两条互补路线：先在大分子/配方库中预测并过滤，或直接用自动实验 + active learning 在连续配方空间闭环优化（PDF p.12 / 印刷 p.6635）。
- Clio 案例从 1.1 M LiPF6 EC/EMC 二元体系出发，在 2 个工作日内完成 42 次实验迭代，25 摄氏度电导率提高到 13.7 mS cm\(^{-1}\)，对应 EC:DMC = 40:60（质量比）和 0.9 m LiPF6（PDF p.13 / 印刷 p.6636）。
- 局域高浓度电解质 LHCE 的案例把 LiFSI:DME 与 LiFSI:TTE 作为变量，以 Coulombic efficiency 和沉积过电位为双目标，用 BO + Pareto front 迭代 5 轮，得到摩尔比 1:1.2:3；无负极电池 100 圈容量保持率为 55%，基准为 45%，CE 为 99.39%（PDF p.23 / 印刷 p.6646）。
- 无氟电解质案例用 GPR + Bayesian model averaging 对近似百万个候选电解质做 7 轮主动学习，得到 4 个性能接近先进体系的溶剂，并观察到醚类在无负极锂金属电池中的持续优势（PDF p.32 / 印刷 p.6655）。
- 添加剂案例把 LUMO 能级和 Li 表面吸附作用能作为核心描述符，用 GCNN + BO 主动学习筛选 260 万个分子，识别出 62 个 SEI 型候选和 106 个 leveler 型候选（PDF p.36 / 印刷 p.6659）。
- AI4B 的边界被明确限定：DFT/MD/光谱只有在为模型生成数据、提供物理约束、构建代理模型或参与闭环决策时，才属于 AI4B 的核心链条（PDF p.27 / 印刷 p.6650）。

### 2.5 局限

- 多数现有工作仍停留在性质预测、候选筛选或局部结构分析；多组分协同、动态界面演化和电极附近局部反应环境的定量描述仍处早期（PDF p.37 / 印刷 p.6660）。
- 数据稀缺、元素空间集中于 Li、N、O、S、C、P、B、Si、F，是领域基础模型的瓶颈；大量文献数据仍需用 LLM 提取和清洗（PDF p.40 / 印刷 p.6663）。
- 黑箱模型限制机理理解；LIME 依赖局部线性近似，SHAP 常需近似计算，两者在高非线性、区间依赖的电解质体系中均有稳定性问题（PDF p.41 / 印刷 p.6664）。
- 小数据、强耦合、多尺度与多目标仍是高压电解质的基本困难；自驱动实验室能缩短周期，但仍需要高质量反馈和可靠闭环（PDF pp.40-42 / 印刷 pp.6663-6665）。

### 2.6 与本项目“电解液溶剂介电常数 + 主动学习”的直接关系

- 原文把碳酸酯、磷酸酯、硼酸酯等高介电常数溶剂与“良好锂盐解离能力/稳定离子传输环境”联系起来，说明介电常数可作为高压体系的关键预筛描述符（PDF p.32 / 印刷 p.6655）。这里主要是定性关联，不是介电常数预测模型。
- 原文的 active learning 用例证明：在小规模自有数据上，用 GPR/贝叶斯模型平均加虚拟空间批量筛选，可以逐轮聚焦高价值区域（PDF p.32 / 印刷 p.6655）。这可以直接迁移到“介电常数预测器 + 采集函数 + 小批量实验”的项目框架。
- 原文建议把分子描述符、溶剂化结构、实验约束和应用场景放进统一框架，并明确把 Bayesian optimization/active learning 视为闭环决策模块（PDF pp.27, 36 / 印刷 pp.6650, 6659）。
- 原文同时强调高压性能不能只由单一 HOMO/LUMO 或体相属性判断，必须纳入界面吸附、溶剂化结构和局部反应路径（PDF p.35 / 印刷 p.6658）。项目若只用介电常数作目标，应把离子电导率、黏度、氧化稳定性和界面相容性作为约束或次级目标。
- 直接空白：该文没有给出介电常数作为 active-learning target 的专门案例。现有 BO/active learning 案例主要优化电导率、CE、过电位、容量保持率或界面性质，说明“介电常数驱动的主动学习”仍有可验证的新颖性。

### 2.7 可复用到 Week 1 的行动项

1. 把“分子层预测”和“配方层优化”拆成两个模型：前者输入分子结构与条件，输出介电常数预测；后者输入组分比例/盐浓度，输出体系介电常数及约束性质。
2. 采用漏斗式流程：物理合理性/合成可得性过滤，代理模型排序，高不确定性样本补充 DFT/MD 标签，最后才进入小批量实验。
3. 以 GPR 或贝叶斯模型平均作为首个主动学习后端，至少比较随机采样、纯 exploitation 和 uncertainty-aware acquisition。
4. 将电导率、黏度、DN/AN、盐解离和氧化稳定性纳入多目标 Pareto 设计，避免把高介电常数误当成高压性能的充分条件。
5. 记录实验批次和时间戳，设计“批次主动学习”而非伪在线逐点采样；每轮更新后同时检查误差、校准、覆盖外推区域和实验命中率。
6. 用 MLMD/量子化学生成少量高价值标签时，先做一致性/误差评估，避免把不同泛函、力场和实验条件下的标签无差别混合。

### 2.8 页码核验点

- PDF p.12 / 印刷 p.6635：液相筛选的两条互补路线，以及 288 种溶剂和 99 种锂盐的候选库。
- PDF p.13 / 印刷 p.6636：Clio 的 42 次迭代、2 个工作日、13.7 mS cm\(^{-1}\)、EC:DMC 40:60 与 0.9 m LiPF6。
- PDF p.32 / 印刷 p.6655：酯类高介电常数/盐解离定性描述，以及约百万候选、7 轮主动学习、4 个溶剂结果。
- PDF p.37 / 印刷 p.6660：多组分协同、动态界面演化和局部反应环境仍处早期。

## 3. Chen 等：Applying Machine Learning to Rechargeable Batteries: From the Microscale to the Macroscale

### 3.1 书目与 DOI

- 作者：Xiang Chen, Xinyan Liu, Xin Shen, Qiang Zhang。
- 题名：*Applying Machine Learning to Rechargeable Batteries: From the Microscale to the Macroscale*。
- 期刊：*Angewandte Chemie International Edition*, 2021, 60, 24354-24366。
- DOI：`10.1002/anie.202107369`；German Edition DOI：`10.1002/ange.202107369`（PDF p.1 / 印刷 p.24354）。

### 3.2 研究范围

这篇 Minireview 按尺度组织 ML 在可充电池中的应用：原子/分子尺度的 DFT、MD、ML 势；介观尺度的 PFM/FEM；实验尺度的图像分析、寿命预测和快充协议优化；最后讨论“理论-实验-数据”耦合（PDF pp.2-11 / 印刷 pp.24355-24364）。它不是电解质专用综述，但较早、明确地把介电常数列入“实验和计算都难获得、适合 ML”的液体电解质性质。

### 3.4 关键结论

- ML 可以同时改造理论工具和实验流程：既提升 DFT/MD 的尺度与效率，也从实验数据中挖掘结构-功能关系和优化策略（PDF pp.3-6 / 印刷 pp.24356-24359）。
- 介电常数和液体电解质黏度被列为“通过传统实验或理论计算难以/昂贵获得”的性质，说明它们尤其适合数据驱动代理模型（PDF p.6 / 印刷 p.24359）。
- 在介观模型中，自由能、介电常数和扩散系数是重要输入；小尺度模型在高复杂度下受限，ML 可用于从原子尺度结果提取这些参数并送入 PFM/FEM（PDF p.8 / 印刷 p.24361）。
- 用前 100 圈信息、124 个 LFP/石墨电芯（寿命 150-2300 圈）训练，寿命预测误差为 9.1%；只用前 5 圈即可区分长/短寿命，误分类测试误差为 4.9%（PDF p.10 / 印刷 p.24363）。
- Bayesian optimization 可在 224 个快充协议候选、16 天内找到高寿命方案，比穷举法快 30 倍以上；优化方案平均 895 圈，对比文献启发策略 728 圈（PDF p.11 / 印刷 p.24364）。
- 作者强调人类知识仍是选择和设计特征、训练算法时不可或缺的部分，不能把 ML 视为自动替代领域判断（PDF p.11 / 印刷 p.24364）。

### 3.5 局限

- 文章较早，尚未覆盖 2025-2026 年的大语言模型、通用分子基础模型和现代自主实验室生态；其 active learning 主要是快充协议优化，不是分子层面的主动学习（PDF pp.10-11 / 印刷 pp.24363-24364）。
- 固态电解质离子电导率案例中，模型有 20 个特征但仅用 39 个实验点训练；原文明确指出监督学习受稀缺数据限制（PDF p.6 / 印刷 p.24359）。
- ML 辅助 PFM/FEM 仍“处于早期”，需要更多验证（PDF p.8 / 印刷 p.24361）。
- 特征设计和训练算法高度依赖专家判断；跨物理尺度、复杂界面和不同实验协议之间仍存在显著鸿沟（PDF pp.2, 11 / 印刷 pp.24355, 24364）。

### 3.6 与本项目“电解液溶剂介电常数 + 主动学习”的直接关系

- 原文明确把液体电解质介电常数视作适合 ML 的“难以直接获得”性质（PDF p.6 / 印刷 p.24359），为本项目选择介电常数作为预测目标提供直接背书。
- 原文把介电常数放入多尺度模型链路：它既可由分子尺度计算/预测，又会作为介观模拟输入（PDF p.8 / 印刷 p.24361）。因此 Week 1 可先把介电常数作为独立代理模型目标，再规划通过多尺度输出影响界面和电池性能。
- 原文的 Bayesian optimization 闭环给出一个重要方法论模板：先用廉价早期指标/代理模型筛选，再让优化器在有限实验中平衡 exploration 与 exploitation（PDF pp.10-11 / 印刷 pp.24363-24364）。
- 但该文只证明 BO 对快充参数有效，没有证明“介电常数主动学习”有效；项目必须自行证明 acquisition 策略优于随机采样，并验证 GPR/集成模型的不确定性是否校准。

### 3.7 可复用到 Week 1 的行动项

1. 把性质分成“可快速测”“可计算但昂贵”“难测难算”三档；介电常数需按所用频率、温度和相态明确归类，避免把不同来源数据混合。
2. 为介电常数建立两条基线：纯溶剂经典描述符模型，以及含组分比例/温度/盐浓度的混合体系模型；后者可借鉴多尺度输入思想。
3. 复刻“早期预测 + BO”的实验思想：先用可快速获得的代理变量筛选，再用实验/高保真计算更新模型，不把全部预算放在初始穷举。
4. 在主动学习评估中加入 224 候选式的小规模实验仿真，报告在相同实验预算下相对随机搜索的加速倍数和最优值差距。
5. 记录并审查专家先验：哪些特征来自物理知识、哪些来自数据驱动；对介电常数模型尤其要报告偶极矩、极化率、氢键和盐解离相关特征的贡献。

## 5. Week 1 的合并优先级

1. **先定义标签，不先选模型。** 介电常数必须带频率、温度、相态和配方条件；缺失条件的数据不得直接合并。
2. **先做可解释基线。** GPR、RF/GBR、岭回归在小样本下比大模型更可控；GPR 还能直接提供主动学习所需的预测方差。
3. **先做离线主动学习。** 在历史数据上模拟 acquisition，比较随机、预测最优和 uncertainty-aware 采样，再决定是否投入实验。
4. **先定义多目标。** 介电常数只作为主目标或筛选门；至少同时记录电导率、黏度、DN/AN、氧化稳定性和可合成性。
5. **先做外推验证。** 随机 CV 会高估性能；应设置留溶剂家族、留盐类型、留浓度区间等分组测试。
6. **先建立闭环记录。** 每次预测必须保存模型版本、候选来源、采集函数、实验批次、结果和反馈时间，保证下一轮可复现。
